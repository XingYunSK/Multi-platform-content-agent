# 执行成本坍塌 vs 判断价值上升

## 构图
上下对比或左右对比布局，强化视觉反差：

### 方案A：上下对比（推荐）

**上半部分：执行成本坍塌**
- 大标题："执行成本"（灰色或浅色调）
- 视觉：一个向下的大幅箭头，指向趋近于零
- 关键数据：
  - "4倍 → 8倍 → 52倍" 效率提升
  - "800个修复 = 4年人力"
  - "趋近于零"
- 辅助元素：代码符号、工具图标（细线线性图标）
- 色调：偏灰、偏冷，暗示"被压缩"

**中间分隔线**：一条细橙色横线，作为视觉转折

**下半部分：判断价值上升**
- 大标题："判断价值"（橙色强调）
- 视觉：一个向上的大幅箭头，指向稀缺/珍贵
- 核心概念：
  - "选择做什么"
  - "什么时候止损"
  - "什么方向值得投入"
- 辅助元素：思考/决策图标（细线线性图标）
- 色调：橙色单点强调，暗示"稀缺"

**底部区域**：三组核心矛盾（小字标签）
- "执行成本坍塌 vs 判断价值上升"
- "产出爆发 vs 注意力瓶颈"
- "自动化速度 vs 组织重构速度"

### 布局
- 上下各占约40%，中间分隔10%，底部10%
- 充足留白，对比强烈但不过度拥挤

## 色彩
- 背景：米白色 (#F5F5F0)
- 上半部分（执行）：灰色系 (#999999, #666666) + 浅灰底色
- 下半部分（判断）：深灰/黑色 (#1A1A1A) + 橙色强调 (#E85D04)
- 分隔线：橙色 (#E85D04)
- 文字：深灰/黑色

## 字体
- 现代无衬线字体观感，接近 Calibri / Inter / Helvetica / Arial
- 大标题醒目，数据标签清晰
- 不要楷体、宋体、Times New Roman、书法体

## 风格关键词
- 新中性资讯风 / 科技商业资讯风 / 媒体杂志排版 / 轻报告视觉
- 低饱和中性色 + 橙色单点强调
- 对比概念图、上下对比布局、箭头导向
- 充足留白、视觉反差强烈
- 不要强科技蓝、不要黑金赛博、不要霓虹、不要复杂3D、不要卡通化

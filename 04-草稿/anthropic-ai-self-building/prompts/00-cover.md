# 封面图：AI自我构建时代，判断力成为稀缺资源

## 构图
极简封面，不做信息图，不堆要素。画面分为三个层次：

1. **顶部区域（约25%高度）**：大标题短句，像新闻结论，短而有力
   - 主标题："80%代码由AI自己写"
   - 副标题："判断力，最后的稀缺资源"
   - 字体：现代无衬线字体观感，接近 Calibri / Inter / Helvetica / Arial，标题有媒体头条感和结论感

2. **中部主体视觉（约50%高度）**：抽象递归/自我构建符号
   - 一个简洁的几何图形：类似莫比乌斯环或递归箭头符号，暗示"AI构建AI"
   - 线条风格：细线、几何、低复杂度
   - 颜色：深灰/黑色主体 + 橙色单点强调（关键节点或路径）
   - 可搭配1-2个极简线性图标：代码括号符号、芯片轮廓

3. **底部区域（约25%高度）**：品牌标识区域
   - "Holamuse" 字样（小字号，低调）
   - 底部一条细橙色横线作为视觉锚点

## 色彩
- 背景：米白色 (#F5F5F0) 或极浅灰
- 主文字：深灰/黑色 (#1A1A1A)
- 强调色：橙色单点 (#E85D04 或类似暖橙)
- 辅助色：浅灰 (#CCCCCC) 用于次要线条

## 风格关键词
- 新中性资讯风 / 科技商业资讯风 / 媒体杂志排版 / 轻报告视觉
- 低饱和中性色 + 橙色单点强调
- 现代无衬线字体，接近 Calibri / Inter / Helvetica / Arial
- 不要楷体、宋体、Times New Roman、书法体
- 极简封面，不做信息图，不堆要素
- 不要强科技蓝、不要黑金赛博、不要霓虹、不要复杂3D、不要卡通化
- 充足留白，高级质感，强识别度

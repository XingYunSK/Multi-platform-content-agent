# 三种情景框架：不是预测，是压力测试

## 构图
三列卡片布局，杂志式信息编排：

### 顶部区域（约15%）
- 大标题："三种情景：不是预测，是压力测试"
- 副标题："Anthropic报告中的三种可能路径"
- 一条细橙色横线分隔

### 三列主体区域（约70%）

**左列：情景一 — 趋势停滞**
- 卡片标题："趋势停滞"（橙色短竖条锚点）
- 核心特征：
  - "AI无法拥有研究品味"
  - "复合式加速仍持续"
  - "人类专注方向设定"
- 关键启示："即使不递归改进，现有加速也足够改变组织"
- 卡片底色：浅灰或白色，轻阴影

**中列：情景二 — 大幅自动化**
- 卡片标题："大幅自动化"（橙色短竖条锚点）
- 核心特征：
  - "生产力乘数效应"
  - "100人 = 1万人工作量"
  - "产出爆发式增长"
- 关键风险："注意力瓶颈——产出超过消化能力"
- 卡片底色：浅灰或白色，轻阴影

**右列：情景三 — 递归自我改进**
- 卡片标题："递归自我改进"（橙色短竖条锚点）
- 核心特征：
  - "速度取决于算力和算法"
  - "人类角色转向监督验证"
  - "虚拟实验室扩张"
- 关键风险："对齐偏差累积，可能失去控制"
- 卡片底色：浅灰或白色，轻阴影

### 底部区域（约15%）
- 总结句："我们可能无法判断自己处于哪条趋势线上"
- 小字注释

## 色彩
- 背景：米白色 (#F5F5F0)
- 主文字：深灰/黑色 (#1A1A1A)
- 强调色：橙色 (#E85D04) 用于卡片标题锚点、关键风险标注
- 辅助色：浅灰 (#E8E8E8) 用于卡片底色
- 三列卡片用统一风格，可用细微色阶区分（左浅→中中→右略深）

## 字体
- 现代无衬线字体观感，接近 Calibri / Inter / Helvetica / Arial
- 标题有结论感，正文清晰
- 不要楷体、宋体、Times New Roman、书法体

## 风格关键词
- 新中性资讯风 / 科技商业资讯风 / 媒体杂志排版 / 轻报告视觉
- 低饱和中性色 + 橙色单点强调
- 卡片化、三列布局、层级清晰
- 充足留白，信息密而不乱
- 不要强科技蓝、不要黑金赛博、不要霓虹、不要复杂3D、不要卡通化

# 任务时长指数曲线：4分钟 → 1.5小时 → 12小时

## 构图
数据可视化图表，清晰展示指数增长趋势：

### 主体区域
- **横轴**：时间线
  - 2024年3月
  - 2025年3月
  - 2026年
  - 预测延伸：2026年底（虚线）

- **纵轴**：任务时长（对数或线性均可，建议线性更直观）
  - 底部标注：4分钟 → 1.5小时 → 12小时

- **曲线**：
  - 从左下角开始，陡峭上升
  - 三个关键节点用橙色圆点标注
  - 节点旁边标注具体数值（中文标签）
  - 曲线末端用虚线延伸，暗示继续增长

- **辅助元素**：
  - 每个节点上方或下方用细线连接文字说明
  - 底部注释："约每四个月翻一番"
  - 右侧或顶部可加小字："如果延续，几天时长的任务也将落入AI能力范围"

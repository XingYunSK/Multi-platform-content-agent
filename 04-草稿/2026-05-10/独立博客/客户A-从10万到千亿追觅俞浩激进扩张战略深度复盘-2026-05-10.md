# 从10万到千亿：追觅俞浩的激进扩张战略深度复盘

> 追觅科技创始人俞浩的争议言论背后，隐藏着怎样的品牌扩张逻辑？本文从运营视角深度解析。

---

追觅创始人俞浩，可能是2026年中国科技圈最具争议的人物之一。

从炮轰小红书算法，到喊出"与华为小米三分天下"的手机梦；从对标布加迪的汽车宣言，到三年万亿营收目标——他的每一次"狂言"，都在舆论场掀起巨大波澜。

有人说他是在"博眼球"，有人说他是"营销鬼才"，更有人说"中国就需要这样的狂人企业家"。

但如果我们剥开舆论的喧嚣，认真审视追觅这家公司的发展轨迹，会发现一些有意思的东西：**俞浩的"激进扩张"战略，背后其实有一套完整的商业逻辑。**

本文将从品牌运营的视角，对追觅的扩张战略进行一次深度复盘。

## 一、追觅是谁：从10万起步到全球第三

### 1.1 创始人背景

俞浩，1987年出生于江苏南通，因物理竞赛获奖保送至清华大学航空航天系。

2009年，还在清华读书的他，与志同道合的伙伴创立了硬科技实验室"天空工场"，专注于飞行器研发。他是中国最早一批四旋翼无人机开发者，也是三旋翼无人机的发明人。

2015年硕士毕业后，俞浩做出了一个让外界意外的选择：放弃当时火热的无人机赛道，转向智能清洁领域。

谈及原因，他在一次采访中直言："无人机终究是小众市场。"而他的创业原则很明确：**要做千家万户都需要、且有高技术壁垒的产品。**

### 1.2 技术破局

当时，戴森凭借一颗转速高达12.5万转/分钟的高速数字马达，在中国市场掀起高端家电风暴；而国产同类产品的马达转速普遍只有1-2万转。

巨大技术差距让俞浩看到了机会：**能不能用造飞机的技术攻克马达难题，打造一家"中国的戴森"？**

带着这个目标，追觅将全部资源聚焦于高速数字马达的研发。历经三年、上千次实验迭代，终于在2017年成功推出首款10万转/分钟的高速数字马达，一举打破戴森长达十余年的技术垄断。

**这笔投资只用了10万元启动资金。**

同年，追觅科技正式成立。

### 1.3 增长轨迹

追觅的发展速度，堪称惊人：

| 年份 | 关键里程碑 |
|------|-----------|
| 2017年 | 成立，加入小米生态链，首款马达量产 |
| 2018年 | 无线吸尘器V9上线6天售罄18888台 |
| 2019年 | 开启自主品牌出海之路 |
| 2021年 | 洗地机业务GMV增长1659%，获36亿C轮融资 |
| 2024年 | 自研20万转/分钟马达（超越戴森） |
| 2025年 | 营收超2024年全年，全球市场份额第三 |
| 2026年 | 登陆美国超级碗，宣布万亿目标 |

**追觅八年平均年增长率达到100%。**

2025年，追觅以10.5%的全球市场份额跃居智能清洁行业第三位；海外营收占比78%，进入全球超120个国家和地区。

## 二、扩张路径：从清洁电器到四面出击

### 2.1 第一个转折：从代工到品牌

2017年底，追觅加入小米生态链，成为米家无线吸尘器的核心供应商。

借助小米生态链的渠道优势与品牌背书，追觅快速实现市场破冰。但俞浩的野心不止于此。

**"追觅不是产品公司，而是科技公司。"** 他曾公开表态，"我们不会做一个小而美的企业，目标是百亿级甚至更大的规模。"

2019年之后，手握融资的追觅毅然开启自主品牌之路，首战便瞄准海外市场。

凭借核心马达技术带来的产品性能优势，追觅的扫地机器人和吸尘器迅速在法国、意大利、西班牙等欧洲主流市场登上品类销量榜首。

### 2.2 2021年：全面腾飞

2021年，追觅迎来了全面腾飞的拐点。

**"人和"——关键人才加盟**

曾任职于宝洁的郭人杰于2021年加入追觅，全面主导品牌与渠道革新。他果断押注抖音电商，通过达人矩阵、精准投放与高频直播的组合策略，快速引爆市场——追觅仅用80天便登顶抖音智能清洁品类榜首。

同期，公司还签约德国足球豪门多特蒙德及中国短跑名将苏炳添，强化全球化品牌形象。

**"天时"——市场风口**

据《2021年中国家电市场报告》，当年洗地机市场从15亿激增至67亿，增速高达356%。追觅抓住机遇，仅一年多时间，洗地机业务GMV增长超1659%，市场占有率提升了40倍。

**"地利"——资本支撑**

2021年10月，追觅获得华兴新经济基金、碧桂园、小米集团等投资机构的36亿元C轮融资，创下智能清洁行业单笔融资金额新高。

### 2.3 跨界扩张：四面出击

或许是担忧主业增长见顶，又或是出于"不做小而美"的执念，俞浩正带着追觅全力寻找第二增长曲线。

| 时间 | 跨界动作 |
|------|----------|
| 2024年 | 试水餐饮赛道（茶饮、咖啡、火锅） |
| 2025年3月 | 进军大家电（空调、冰箱、洗衣机） |
| 2025年8月 | 宣布造车（对标布加迪） |
| 2025年9月 | 成立天文业务BU（空天地一体化战略） |
| 2025年9月 | 进军手机（"与华为小米三分天下"） |

从清洁电器到大家电、手机、汽车、无人机、天文探索，追觅勾勒出一个"人-车-家-太空-宇宙"的生态叙事。

## 三、争议背后：激进扩张的得与失

### 3.1 争议焦点

追觅的激进扩张引发了广泛争议，主要集中在以下几点：

**1. 边界在哪里？**

俞浩说："追觅的边界是什么？我现在还不知道边界在哪里，不过肯定不是制造。"

这番话引发了"俞浩宇宙"的调侃。有媒体评价，追觅正在变成"硬件版的字节跳动"——不设边界，什么都做。

**2. 核心高管流失**

过去三年间，追觅多位核心高管相继出走并自立门户：

- 前常务副总裁王生乐 → 创立泳池清洁机器人公司
- 创始合伙人吴鹏 → 创办咖啡机品牌
- 人形机器人业务负责人喻超 → 创立具身智能机器人公司
- 中国区执行总裁郭人杰 → 创办具身智能机器人公司

核心人才密集出走，引发外界对追觅内部管理问题的猜测。

**3. 融资空窗**

截至2026年4月，追觅融资空窗期已达35个月。对比2021年单笔36亿元C轮融资的盛况，一级市场对智能清洁赛道的投资态度明显趋于谨慎。

**4. 国内市场份额下滑**

2025年7月起，追觅对主力产品提价10%-15%，直接导致市场份额下滑。2025年双十一，追觅销售额同比下降10%-15%，市场份额较2024年同期缩水约10个百分点。

### 3.2 支持声音

**昆仑万维董事长周亚辉（追觅早期投资人）：**

> "中国就需要这样的狂人企业家。俞浩的'疯狂'背后，其实是一种极度理性。新一代企业家，要找到肥沃土壤、长成巨头，只能靠拼命的试，去调动超出自身能力的资金、产业链能力和渠道资源。"

**俞浩本人回应：**

> "大家以为我在赌，是因为我定了一个大家看来很难的目标。他们把目标大和难，称之为吹牛和赌。我其实厌恶风险，我不喜欢赌。在自主品牌能做成之前，我同时做米家和自主品牌，而不赌自主品牌一定能成功。"

### 3.3 战略得失分析

| 得 | 失 |
|----|----|
| 品牌曝光最大化 | 资源分散，核心业务承压 |
| 话题热度持续高位 | 核心高管流失 |
| 生态叙事吸引资本 | 融资压力加大 |
| 海外市场验证成功 | 国内份额下滑 |
| 差异化认知建立 | 舆论风险累积 |

## 四、运营启示：俞浩战略对品牌扩张的借鉴意义

### 4.1 争议即流量：学会制造话题

俞浩的每一次"狂言"，都带来巨大的媒体曝光。这种"争议营销"策略，值得品牌运营者思考：

**关键洞察：** 在信息过载的时代，有立场的表达比四平八稳的废话更容易传播。

**实操建议：**
- 品牌表达要有明确立场，不必讨好所有人
- 争议要围绕核心定位，而非为了博眼球
- 真性情比"端着"更有穿透力

### 4.2 差异化认知：占据心智位置

俞浩通过一次次"狂言"，让"争议营销"成为追觅的标签之一。

**关键洞察：** 品牌需要在消费者心智中占据一个独特位置，而不仅仅是提供产品功能。

**实操建议：**
- 明确品牌想要占据的1-2个关键词
- 所有传播内容围绕核心定位展开
- 通过持续、一致的表达强化认知

### 4.3 多品类扩张：找到核心能力复用路径

俞浩的扩张逻辑并非随机，而是围绕"高速数字马达"这一核心技术展开——吸尘器、扫地机、洗地机、吹风机、空调、冰箱……核心都是高速马达驱动。

**关键洞察：** 多品类扩张要找到核心能力的复用路径，而非盲目多元化。

**实操建议：**
- 分析品牌的核心技术/能力是什么
- 评估哪些新品类能复用这一核心能力
- 新品类要与核心能力形成协同，而非稀释

### 4.4 全球化布局：先难后易

追觅的全球化路径选择了"先难后易"：先打欧洲高端市场，再逐步扩展。

这与很多国内品牌的"先易后难"策略形成鲜明对比。

**关键洞察：** 在高端市场建立品牌认知，可以为后续扩展提供势能。

**实操建议：**
- 评估目标市场的高端机会
- 如果有能力，先打高端市场建立势能
- 避免在成熟市场进行无底线价格战

## 五、总结与行动清单

### 核心结论

俞浩的激进扩张战略，既有其成功的逻辑（技术突破、品牌差异化、全球化布局），也有其风险（资源分散、人才流失、舆论压力）。

**对品牌运营者而言，更重要的是理解争议营销背后的传播逻辑：**

1. **有立场的表达比四平八稳更有传播价值**
2. **争议只是手段，差异化认知才是目的**
3. **真性情比"端着"更有穿透力**
4. **多品类扩张要找到核心能力复用路径**

### 行动清单

1. **审视品牌表达：** 你的品牌有明确的立场吗？
2. **建立差异化认知：** 你的品牌想占据什么关键词？
3. **评估核心能力：** 品牌最核心的技术/能力是什么？哪些品类可以复用？
4. **思考全球化路径：** 是否有能力/必要进入高端国际市场？
5. **平衡激进与稳健：** 扩张的边界在哪里？如何控制风险？

## 常见问题（FAQ）

**Q1：争议营销适合所有品牌吗？**

A：不是。争议营销需要两个前提：一是产品/服务经得起检验；二是品牌有能力承担舆论风险。初创品牌或处于信任建立期的品牌，建议谨慎使用。

**Q2：追觅的跨界扩张会成功吗？**

A：目前无法定论。追觅的核心优势（高速马达）在大家电、手机、汽车等领域是否构成真正的差异化竞争力，还需要市场验证。建议持续观察。

**Q3：普通品牌如何借鉴俞浩的策略？**

A：不需要模仿他的"狂言"，而是要学习他的底层逻辑：有立场、找差异化、真性情、核心能力复用。

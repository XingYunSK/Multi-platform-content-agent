## 🔄 如何切换样式

### 方法 1：直接覆盖（推荐）

1. 打开想要的样式文件（如 `02-清新绿.md`）
2. 复制 CSS 代码部分
3. 打开 `Templates/自定义样式.md`
4. 粘贴覆盖原有 CSS
5. 在 Obsidian 中刷新 NoteToMP 预览

### 方法 2：多套备用

可以创建多个样式文件：
- `自定义样式 - 简约.md`
- `自定义样式 - 清新.md`
- `自定义样式 - 科技.md`

需要时复制内容到 `自定义样式.md`

## 🎯 推荐搭配

### XPEL 汽车膜

### 生活随笔

- 温暖橙：活泼亲切

## 💡 自定义建议

可以混合不同样式的元素：
- 用科技蓝的标题 + 简约黑的正文
- 用温暖橙的列表 + 清新绿的引用
- 调整颜色代码匹配品牌色

**品牌色替换：**
找到 CSS 中的颜色代码，替换成你的品牌色即可。

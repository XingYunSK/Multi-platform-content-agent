# 热点4：李彦宏称AI时代度量衡是日活智能体数（DAA）

## 原文素材1-IT之家

**标题**：百度李彦宏称 AI 时代的度量衡不是 Token 消耗，而是日活智能体数（DAA）

**来源**：IT之家
**链接**：https://www.ithome.com/0/949/663.htm
**时间**：2026年5月13日 10:44

---

在今日的 Create 2026 百度 AI 开发者大会上，百度创始人李彦宏提出，AI 时代的度量衡可能是"日活智能体数"（Daily Active Agents，简称 DAA），与移动互联网最通用的度量衡"日活用户数"（DAU）相对应。

李彦宏表示，目前较接近业界共识的度量衡是 Token 消耗，但 Token 不一定代表终局，它代表成本，并不代表收益；它衡量的是投入，而不是产出。"当人类进入智能体时代，衡量一个平台和生态的繁荣，更应该关注 DAA 这个指标，关注有多少 Agents 在给人类干活，并交付结果。这比无谓的 Token 消耗，更接近价值，也更接近本质。"

李彦宏还称，在今天的智能体浪潮驱动下，人类个体也在自我进化，Builder、Founder、Creator 实现了三位一体，每一个开发者，同时也是创业者，更是创造者。

IT之家从官方议程表获悉，Create 2026 百度 AI 开发者大会于 5 月 13 日 ~14 日在北京国家会议中心二期举行，地平线创始人兼 CEO 余凯、星海图 CEO 高继扬等也将出席大会开幕式。

---

## 核心观点

**李彦宏原话**：

> AI 时代的度量衡可能是"日活智能体数"（DAA），与移动互联网的"日活用户数"（DAU）相对应。

> Token 代表成本，并不代表收益；衡量的是投入，而不是产出。

> 关注有多少 Agents 在给人类干活，并交付结果。比无谓的 Token 消耗，更接近价值，也更接近本质。

---

## 关键概念对比

| 指标 | 代表含义 | 说明 |
| ---- | ---- | ---- |
| Token | 成本/投入 | AI消耗的资源量 |
| DAA（日活智能体数） | 价值/产出 | AI实际交付的结果 |

---

## DAA的定义

**DAA = Daily Active Agents**

- **D**：Daily（每日）
- **A**：Active（活跃）
- **A**：Agents（智能体）

衡量标准：有多少智能体在给人类干活并交付结果

# 背景资料 | 小红书AI战略升级

## 历史发展脉络

| 时间 | 事件 | 战略意义 |
|------|------|----------|
| 2013年 | 小红书成立 | 定位为真实生活方式分享社区 |
| 2014年 | 上线"福利社" | 探索电商变现 |
| 2019年 | 探索"小绿洲" | 新零售业态尝试 |
| 2023年 | 内部筹备大模型团队 | AI布局开始 |
| 2024年 | 推出AI搜索产品"点点" | AI产品化尝试 |
| 2025年 | 与淘宝天猫、京东达成战略合作 | 放弃全链路闭环 |
| 2025年7月 | slogan改为"你的生活兴趣社区" | 强调归属感 |
| 2026年4月 | 俞浩"炮轰"小红书 | 信任危机爆发 |
| 2026年4月30日 | 成立AI一级部门Dots | AI升格为一级部门 |
| 2026年5月 | NLP经营方法论发布 | AI落地电商 |

## 小红书的商业化困境

### 钟摆困境
- **护住社区调性** → 拖累商业化效率
- **推高交易效率** → 磨损社区调性
- 这个钟摆摇了十年也没停稳

### 护城河分析

**优势**：
- 4亿月活用户
- 十二年真实生活内容沉淀
- 年轻用户浓度高
- 消费决策影响力强

**劣势**：
- 种草容易拔草难
- 供应链、物流、售后等重资产缺失
- 与轻巧精致的社区基因冲突

### 定位演变

| 阶段 | 定位 |
|------|------|
| 买手电商 | 强调买手个人品牌 |
| 生活方式电商 | 强调生活方式 |
| 好货平台 | 强调商品品质 |
| AI驱动的生活决策入口 | 强调AI赋能 |

## AI布局延迟原因

### 不是看不清趋势
- 早在2023年就有大模型团队筹备
- 2024年推出AI搜索产品

### 而是不敢放开手
- 等待龙虾（OpenClaw）事件发酵
- 先清理AI托管账号
- 再正式推出AI战略

**逻辑**：
> "不是不看好AI，而是太清楚AI这把刀有多锋利，必须先打造一副能握刀的手套。"

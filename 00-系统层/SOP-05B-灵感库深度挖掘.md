# SOP-05B-灵感库深度挖掘

> 当选题来源为灵感库时，执行本流程。
>
> **触发条件**：用户选择灵感库选题 OR 灵感库选题评分≥70进入正式选题

---

## 零、前置判断

> AI 在开始选题规划前，必须先问用户：

```
今日选题来源：
[A] 热点驱动 → 执行 SOP-03 热点抓取 → SOP-05 选题规划
[B] 灵感库选取 → 执行本流程（SOP-05B）
[C] 固定栏目（IP名人堂/月度盘点）→ 跳转对应固定选题
[D] 备用选题池 → 读取 03-选题库/备用选题池/
```

**如用户未指定，AI 应主动询问。**

## 一、读取灵感库

### 操作步骤

1. **读取灵感库索引**
  - 读取 `03-选题库/灵感库.md`

2. **筛选可激活灵感**
  - 过滤条件：

    - 选题时间≤30天（新鲜度）
    - 热度≥🔥🔥🔥（传播潜力）

  - 按目录分类列出（每类≤5个）

## 二、深度信息挖掘

> 灵感选好后，必须执行深度挖掘，**灵感不搜索 = 选题不完整**

### 触发条件

- 灵感关联热点已有素材库 → 直接复用，跳到"选题卡生成"
- **灵感无关联热点** → 必须执行本流程
- **灵感有热点但素材库不完整** → 补充挖掘

### 挖掘方向（按支柱类型）

**P2-IP名人堂灵感挖掘**


| 信息类型  | 挖掘内容         | 信息来源        |
| ----- | ------------ | ----------- |
| 人物近况  | 最新动态/发言/动作   | X/微博/36氪/虎嗅 |
| 历史事件  | 关键里程碑时间线     | 官方公告/深度报道   |
| 争议/反转 | 公众评价变化/关键分歧点 | 行业媒体/社交媒体   |
| 行业影响  | 对所在行业的影响     | 专业分析/研报     |
| 可学方法  | 提炼3条可复用方法论   | AI归纳        |
| 金句储备  | 原话引用（3-5句）   | 原文提取        |


**P3-平台策略灵感挖掘**


| 信息类型  | 挖掘内容           | 信息来源             |
| ----- | -------------- | ---------------- |
| 官方公告  | 平台政策/算法更新的官方原文 | 平台公众号/官方博客       |
| 实操案例  | 具体操作步骤/案例截图    | 成功账号分析/教程        |
| 数据支撑  | 具体数字/比例/效果对比   | 行业报告/平台数据        |
| 行业解读  | 专业媒体对规则的解读     | 36氪/人人都是产品经理/运营派 |
| 避坑指南  | 常见错误/红线        | 踩坑案例/官方公告        |
| 模板/工具 | 可直接使用的模板/工具    | 社区分享/自整理         |


**P3-AI工具使用灵感挖掘**


| 信息类型     | 挖掘内容           | 信息来源      |
| -------- | -------------- | --------- |
| 工具能力     | 核心功能/更新日志      | 官方文档/版本说明 |
| 实操演示     | 详细步骤/参数设置      | 教程文章/视频   |

| 信息类型 | 挖掘内容           | 信息来源      |
| ---- | -------------- | --------- |
| 官方原文 | 政策/规则的官方公告     | 平台公告/监管机构 |

| 违规案例 | 具体违规行为及处罚结果    | 官方公告/媒体报道 |

## 三、选题卡生成

### 操作步骤

1. **匹配选题主题库**
  - 读取 `01-知识库/01-客户档案库/Holamuse/05-内容策略/选题主题库.md`
  - 确定灵感对应的内容支柱（P1/P2/P3）和领域
2. **读取平台选题模板**
  - 读取 `03-选题库/各平台选题模板.md`
  - 选取对应支柱×平台的标题模板
3. **生成标题备选**
  - 至少3个标题选项
  - 标注每个标题的：类型 / 来源模板 / 差异化说明
4. **生成选题卡**
  - 按 SOP-05 选题卡模板生成
  - 必须包含：素材引用说明（来自深度挖掘结果）
5. **标注灵感来源**
  - 选题卡头部标注：`灵感来源：灵感卡-XXX.md`
  - 方便后续归档

### 选题卡新增字段

```markdown
## 灵感来源

| 项目 | 内容 |
|------|------|
| 灵感编号 | [灵感编号] |
| 灵感标题 | [灵感标题] |
| 来源目录 | [P2-IP名人堂/P3-平台策略/...] |
| 搜索深度 | [完整/补充/直接复用热点素材] |
| 热点关联 | [关联热点标题/无需热点] |
```

## 五、异常情况处理


| 异常            | 处理方式               |
| ------------- | ------------------ |
| 灵感无关联热点且搜索结果少 | 降低优先级，待素材充足时再激活    |
| 灵感过时（>60天）    | 归档到「灵感归档」或删除       |
| 灵感与当月选题计划重复   | 标记"本月不激活"，保留       |
| 搜索结果涉及敏感内容    | 立即停止，标注"敏感"，通知项目经理 |

## 六、灵感库维护节奏


| 周期      | 动作                |
| ------- | ----------------- |
| 每日灵感库新增 | 随时记录新灵感           |
| 每周五整理   | 评估灵感池，筛选可激活选题     |
| 每月末     | 从灵感池升级正式选题（评分≥70） |
| 每季度     | 归档过时灵感（>90天未激活）   |

# 帮我开始今日SOP

## 使用场景

每天早上启动工作流时，一句话触发完整流程。

## 触发词

- "帮我开始今日SOP" / "开始今天的工作" / "今日工作流" → AI 自主执行模式
- "今天状态怎么样" / "状态回顾" → 项目经理快速回顾模式

## 模式一：AI 自主执行

```
请帮我执行今日内容运营工作流：

## 第一步：加载上下文
1. 读取 SOP-01 每日工作流，确认今日工作步骤
2. 读取当前客户的品牌规范：
   - 01-知识库/01-客户档案库/[当前客户]/品牌规范.md
   - 01-知识库/01-客户档案库/[当前客户]/产品信息/产品矩阵.md
3. 读取本月内容规划：03-选题库/规划/月度选题日历.md（如存在）

## 第二步：热点抓取
4. 执行 SOP-03 热点抓取流程
5. 查看今日热点简报：02-热点池/日报/今日热点简报-YYYY-MM-DD.md

## 第三步：深度素材挖掘
6. 对入选热点执行 SOP-04 深度素材挖掘四步法
7. 检查素材库完整性：02-热点池/素材库/YYYY-MM-DD/[热点]/

## 第四步：热点最终筛选
8. 查看热点最终筛选：02-热点池/日报/热点最终筛选-YYYY-MM-DD.md

## 第五步：选题确认
9. 查看选题卡：03-选题库/选题卡/
10. 确认今日写作选题

## 第六步：输出今日工作清单
11. 给我今日工作清单：
    - 今日重点选题（1-2个）
    - 对应客户和平台
    - 流程阶段说明
```

## 模式二：项目经理快速回顾

```
今天状态怎么样？
```

AI 输出内容：

```
## 系统健康度报告 | YYYY-MM-DD

### 热点池
- 今日入库：X 条（正常 / 偏少）
- Top 热点：...

### 素材库
- 入选热点素材完整性：X 个热点 ≥3 来源

### 选题库
- 待创作：X 篇（积压 >3天：列出详情）
- 今日入选：X 个

### 草稿
- 待审核：X 篇
- 红灯率：X%（>20% 需关注）

### 待确认事项
1. [具体事项 + 负责人]
2. [具体事项 + 负责人]
```

## 注意事项

- 默认客户为"Holamuse"，如需切换请在指令中说明
- 如热点抓取失败，自动使用选题库中的备用选题
- 每次数据复盘后，将关键发现追加至 `01-知识库/04-用户记忆库/`

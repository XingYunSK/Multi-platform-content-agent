# 帮我开始今日SOP

## 使用场景

每天早上启动工作流时，一句话触发完整流程。

## 触发词

- "帮我开始今日SOP" / "开始今天的工作" / "今日工作流" → AI 自主执行模式
- "今天状态怎么样" / "状态回顾" → 项目经理快速回顾模式

## 模式一：AI 自主执行

```
请帮我执行今日内容运营工作流：

## 第零步：确认选题来源（必须先问）

在开始任何操作前，先向用户确认：

```

今日选题来源：
[A] 热点驱动 → 执行热点抓取 → 选题规划（SOP-05）
[B] 灵感库选取 → 灵感库深度挖掘（SOP-05B）
[C] 固定栏目（IP名人堂/月度盘点）→ 跳转对应固定选题
[D] 备用选题池 → 读取 03-选题库/备用选题池/
[E] 客户指定选题 → 读取客户需求 → 直接进入选题卡生成

请选择今日选题来源：[A/B/C/D/E]

```

**重要：AI 必须先确认选题来源，再执行对应流程，不得跳过此步骤。**

---

## 分支A：热点驱动

### 第一步：加载上下文
1. 读取 SOP-01 每日工作流，确认今日工作步骤
2. 读取当前客户的品牌规范：
   - 01-知识库/01-客户档案库/Holamuse/品牌规范.md
   - 01-知识库/01-客户档案库/Holamuse/产品信息/产品矩阵.md
3. 读取本月内容规划：03-选题库/选题规划总表.md

### 第二步：热点抓取
4. 执行 SOP-03 热点抓取流程
5. 查看今日热点简报：02-热点池/日报/今日热点简报-YYYY-MM-DD.md

### 第三步：深度素材挖掘
6. 对入选热点执行 SOP-04 深度素材挖掘四步法
7. 检查素材库完整性：02-热点池/素材库/YYYY-MM-DD/[热点]/

### 第四步：热点最终筛选
8. 查看热点最终筛选：02-热点池/日报/热点最终筛选-YYYY-MM-DD.md

### 第五步：选题确认
9. 执行 SOP-05 选题规划流程
10. 查看选题卡：03-选题库/选题卡/
11. 确认今日写作选题

### 第六步：输出今日工作清单
12. 给用户今日工作清单：
    - 今日重点选题（1-2个）
    - 对应客户和平台
    - 流程阶段说明

---

## 分支B：灵感库选取

### 第一步：加载上下文
1. 读取 SOP-01 每日工作流
2. 读取 SOP-05B 灵感库深度挖掘流程
3. 读取当前客户的品牌规范：
   - 01-知识库/01-客户档案库/Holamuse/品牌规范.md
   - 01-知识库/01-客户档案库/Holamuse/产品信息/产品矩阵.md

### 第二步：读取灵感库
4. 读取灵感库索引：03-选题库/灵感库.md
5. 按目录分类列出可激活灵感（P2-IP名人堂 / P3-平台策略 / P3-AI工具使用 / P3-行业新规解读）
6. 每条注明：编号 / 核心想法 / 热度 / 关联热点 / 更新时间

### 第三步：用户选择灵感
7. 列出灵感池供用户选择（每类≤5个优先级最高的）
8. 用户确认后，选定灵感编号

### 第四步：深度信息挖掘
9. 执行 SOP-05B 深度挖掘：
   - 关联热点已有素材 → 直接复用
   - 无关联热点 → 必须搜索收集信息
   - 热点有但素材不足 → 补充挖掘
10. 收集标准：
    - 原文素材 ≥2个来源
    - 数据支撑 ≥3个数字
    - 金句/观点 ≥3条
    - 案例/实操 ≥1个

### 第五步：选题卡生成
11. 执行 SOP-05 选题卡生成流程
12. 匹配选题主题库，确定支柱类型
13. 读取平台选题模板，生成标题备选
14. 生成选题卡，标注灵感来源

### 第六步：更新灵感库状态
15. 更新灵感卡片状态（已激活）
16. 记录激活日期和选题卡编号

### 第七步：输出今日工作清单
17. 给用户今日工作清单：
    - 灵感选题（1-2个）
    - 对应客户和平台
    - 深度挖掘状态

4. 直接进入选题卡生成

## 分支D：备用选题池

### 执行逻辑
1. 读取 `03-选题库/备用选题池/` 全部文件
2. 评估哪些选题可以立即激活
3. 补充搜索相关信息
4. 进入选题卡生成

## 分支E：客户指定选题

### 执行逻辑
1. 读取客户指定需求
2. 匹配客户档案
3. 如需补充素材，执行素材挖掘
4. 直接进入选题卡生成
```

```
## 注意事项

- 默认客户为"Holamuse"，如需切换请在指令中说明
- 如热点抓取失败，自动使用选题库中的备用选题
- 每次数据复盘后，将关键发现追加至 `01-知识库/04-用户记忆库/`
- 灵感库选取时，必须先展示可激活灵感列表，由用户选择，不得自行决定激活哪个
- 灵感库选题必须执行深度挖掘，搜索信息不完整不得进入选题卡生成
```

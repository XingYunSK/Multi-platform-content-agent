# 帮我生成标题备选

## 使用场景
文章初稿完成后，生成多个标题备选供选择。

## 触发词
- "帮我生成标题"
- "起个标题"
- "多几个标题备选"

## 指令内容

```
请根据以下文章初稿，生成5个标题备选：

## 标题要求
1. 符合[平台]平台调性
2. 符合[客户名]品牌调性
3. 每种类型至少1个：
   - 冲突型：制造认知冲突，引发好奇
   - 反问型：提出问题，引发思考
   - 数字型：用具体数字吸引眼球
   - 反直觉型：颠覆常识，引发讨论
4. 字数控制在20字以内

## 输出格式

| 类型 | 标题 | 适合原因 |
|------|------|----------|
| 冲突型 | [标题] | [原因] |
| 反问型 | [标题] | [原因] |
| 数字型 | [标题] | [原因] |
| 反直觉型 | [标题] | [原因] |
| 悬念型 | [标题] | [原因] |

## 推荐
基于文章内容，推荐最优标题及理由。
```

## 后续处理
- 选择标题后更新文章文件名前缀
- 备选标题存入 `04-草稿/[平台]/标题备选/[文章名]-备选.md`

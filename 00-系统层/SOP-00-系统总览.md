## SOP 依赖关系

```
SOP-03 热点抓取
    ↓
SOP-04 深度素材挖掘（依赖 SOP-03 输出）
    ↓
SOP-05 选题规划（依赖 SOP-03 + SOP-04 输出）
    ↓
SOP-06 内容创作（依赖 SOP-05 选题卡 + 知识库）
    ↓
SOP-07 审核发布（依赖 SOP-06 草稿，四道审核防线：合规×3 + 质量评分）

SOP-02 知识库配置 ← 全流程底层依赖（任何创作步骤前必须检索）
SOP-01 每日工作流 ← 流程编排总览（串联合并所有 SOP），不直接参与数据流
```

**可并行执行的部分：**

- 同一热点的多平台内容创作（公众号/小红书/博客）可并行生成
- 热点脱水分析与上一热点素材挖掘可并行（SOP-03 Step 6 与 Step 1-5）

## 快速启动

### 模式一：AI 自主执行（早上启动）

```
请帮我执行今日内容运营工作流：

1. 读取 SOP-01 确认今日工作步骤
2. 读取当前客户的品牌规范：
   - 01-知识库/01-客户档案库/[当前客户]/品牌规范.md
   - 01-知识库/01-客户档案库/[当前客户]/产品信息/产品矩阵.md
3. 执行热点抓取流程（SOP-03）
4. 执行深度素材挖掘流程（SOP-04）
5. 筛选选题并生成选题卡（SOP-05）
6. 输出今日工作清单（含重点选题/客户/平台/预计完成时间）
```

### 模式二：项目经理快速回顾

```
今天状态怎么样？
→ 输出：健康度自检报告 + 待确认事项 + 今日发布预览
```

## 系统健康度自检（每次启动前必做）


| 检查项     | 正常状态          | 异常处理                   |
| ------- | ------------- | ---------------------- |
| **热点池** | 今日有新热点入库      | 无 → 启动 `02-热点池/备用选题池/` |
| **素材库** | 入选热点≥3个来源     | 不足 → 补充抓取或降级为"跟进"      |
| **选题库** | 待创作选题积压 ≤ 3 天 | 超期 → 标记废弃或重新评估         |
| **草稿**  | 红灯率 ≤ 20%     | 超标 → 暂停，检查 SOP-06 质量标准 |
| **发布**  | 昨日文章已归档       | 遗漏 → 立即手动归档            |
| **知识库** | 客户档案是最新的      | 过期 → 提醒项目经理更新          |

## 配置检查清单（新系统首次启用）

- 至少1个客户档案已创建（`01-知识库/01-客户档案库/[客户名]/`）
- 品牌规范已填写（`01-知识库/01-客户档案库/[客户名]/品牌规范.md`）
- 合规风控库已配置（`01-知识库/02-合规风控库/`）
- 各平台人设Prompt已配置（`01-知识库/03-品牌调性库/微信公众号/` / `小红书/` / `独立博客/`）
- 测试文章已通过全流程验证

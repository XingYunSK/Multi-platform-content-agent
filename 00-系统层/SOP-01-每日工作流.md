# 每日工作流

> 从热点抓取到内容输出的完整流程 | 角色 / 操作 / 输出物

---

## 角色定义


| 角色       | 说明                          |
| -------- | --------------------------- |
| AI Agent | 自动执行热点抓取 / 素材挖掘 / 内容创作 / 审核 |
| 项目经理     | 人工确认：热点入选 / 选题方向 / 异常决策     |
| 审核人      | 人工复核：红灯内容 / 品牌调性偏离          |


---

## 全流程总览

```
① 热点抓取（AI Agent）
  → 原始素材入库 + 今日热点简报（Top 15）

  ↓

② 热点脱水（AI Agent）
  → AI 评分 → 筛选 → 脱水 → 热点最终筛选（Top 3-5）

  ↓

③ 深度素材挖掘（AI Agent）
  → 对 Top 3-5 热点执行四步法

  ↓

④ 热点最终确认（项目经理）
  → 确认入选热点 / 剔除敏感热点 / 调整优先级

  ↓

⑤ 选题卡生成（AI Agent）
  → 匹配客户档案 → 生成含素材引用的选题卡

  ↓

⑥ 选题方向确认（项目经理）
  → 确认选题方向 / 调整切入角度 / 确认平台分配

  ↓

⑦ 内容创作（AI Agent）
  → 生成标题备选（≥3个选项）→ 确认标题 → 读取素材库 → 检索知识库 → 生成初稿 → 生成配图 → 自检打磨 → 真人感检测（SOP-06C）→ 提交合规审核（SOP-07）

⑧ 合规审核（AI Agent + 审核人）
  → 三道防线扫描 → 绿灯直接进待发布 → 黄灯修改后进入 → 红灯打回重写

⑨ 发布执行（人工）
  → 发布确认 → 定时发布 → 归档 → 48h数据复盘 → 记录到用户记忆库
```

---

## 阶段一：热点抓取（AI Agent）

### 操作步骤

1. **检查去重记录**
  - 读取 `02-热点池/日报/` 目录，检查今日是否已有相同热点
  - 读取 `02-热点池/素材库/` 近7日素材，检查话题重复
2. **多源数据抓取**
  - 聚合热榜：tophub.today（微博/知乎/抖音/B站/微信/36氪/虎嗅）
  - 垂直媒体：数英网 / 运营派 / 人人都是产品经理 / 虎嗅 / 机器之心 / 掘金 / 少数派 / 新榜
3. **三重去重**
  - 第一重：7天内相同话题 → 标记"跟进"
  - 第二重：标题指纹相似度>70% → 合并或跳过
  - 第三重：摘要重复>50% → 跳过
4. **AI 评分筛选**
  - 保留 Top 15，按时效性(30%) + 客户关联(30%) + 多平台适配(25%) + 素材丰富度(15%) 评分
5. **生成今日热点简报**
  - 每条含：来源 / 热度 / 核心事件 / 关联客户 / 推荐指数 / 去重状态

### 输出物

- `02-热点池/原始素材/原始素材-YYYY-MM-DD.md`
- `02-热点池/日报/今日热点简报-YYYY-MM-DD.md`

### 质量门槛

- 正文字数 < 300字 → 丢弃
- 列表页 / 聚合页 → 丢弃
- 内容重复（摘要相似度>50%）→ 跳过

---

## 阶段二：热点脱水与最终筛选（AI Agent）

### 操作步骤

1. **脱水分析**
  - 对 Top 15 执行脱水分析，提取核心事件、一句话概括
2. **AI 二次筛选**
  - 结合客户档案，评估每个热点与客户的关联强度
  - 生成 Top 3-5 入选热点列表
3. **生成热点最终筛选**
  - 每条含完整素材引用说明
  - 标注推荐切入角度

### 输出物

- `02-热点池/日报/热点最终筛选-YYYY-MM-DD.md`

### 项目经理确认

1. 快速浏览热点最终筛选（2分钟）
2. 确认热点准确性
3. 审核选题方向是否符合品牌调性
4. 特殊情况：敏感内容 → 标记"舍弃"
5. 有额外选题需求 → 手动添加选题卡

---

## 阶段三：深度素材挖掘（AI Agent）

### 执行时机

前置条件：热点最终筛选已完成并经项目经理确认。

### 四步法

**第一步：多来源交叉验证**

- 每个热点至少从3个不同来源获取完整原文
- 来源优先级：官方公告 > 专业媒体 > 行业媒体 > 平台数据 > KOL解读 > 用户UGC

**第二步：原文素材抓取**

- 获取每个来源的完整正文（≥500字）
- 保留完整段落格式，标注可引用数据

**第三步：背景资料挖掘**

- 历史背景：这个趋势从何时开始？经历了哪些节点？
- 行业背景：市场规模、主要玩家、增长趋势
- 政策背景：相关法规、监管趋势、对行业影响

**第四步：多角度观点收集**

- 官方视角：平台/官方公告原文
- 行业视角：专家/分析师观点
- 竞品视角：竞争对手有何动作
- 用户视角：普通用户真实反馈

### 输出物

```
02-热点池/素材库/YYYY-MM-DD/[热点标题]/
├── 原文素材1.md       ← 完整原文，500+字
├── 原文素材2.md       ← 完整原文，500+字
├── 原文素材3.md       ← 第三来源（可选）
├── 背景资料.md        ← 含历史/行业/政策背景
└── 多角度观点.md      ← 含官方/行业/竞品/用户视角
```

### 质量检查


| 检查项   | 最低要求 | 优秀标准    |
| ----- | ---- | ------- |
| 原文来源数 | ≥3个  | ≥5个     |
| 单来源字数 | 500字 | 1000字以上 |
| 背景资料  | 1种   | 3种齐全    |
| 观点角度  | 3个   | 4个齐全    |

## 阶段四：选题卡生成（AI Agent）

### 前置条件

- 热点最终筛选已确认（阶段二）
- 深度素材库已构建（阶段三）

### 操作步骤

1. **读取输入**
  - 读取 `02-热点池/日报/热点最终筛选-YYYY-MM-DD.md`
  - 读取 `02-热点池/素材库/YYYY-MM-DD/[热点]/` 全部素材
2. **匹配客户档案**
  - 读取当前客户品牌规范
  - 读取客户产品矩阵
  - 分析热点与客户的关联强度
3. **矩阵分配**
  - 对每个强关联热点，生成多平台分发方案
  - 每个热点×客户至少覆盖1个平台
4. **生成选题卡**
  - 含标题 / 切入点 / 素材引用说明 / 预估字数
  - 按平台分别生成创作方案

### 项目经理确认

1. 确认选题方向
2. 调整切入角度
3. 确认客户分配
4. 确认素材深度是否足够

### 输出物

- `03-选题库/选题卡/选题卡-YYYY-MM-DD-001.md`

## 阶段五：内容创作（AI Agent）

### ⭐ 前置条件

- 选题卡已通过项目经理确认（阶段四）
- ⭐ **必须读取 SOP-06-内容创作.md**（质量标准/写作模板/配图规范/版本管理）

### 操作步骤

1. **读取 SOP-06-内容创作**
  - 完整读取 `00-系统层/SOP-06-内容创作.md`
  - 确认本次创作平台对应的写作规范（公众号/小红书/博客）
  - 确认配图生成流程和比例要求
  - 确认版本命名规则
2. **读取素材库**
  - 读取对应热点素材库全部文件
  - 确认素材引用清单
3. **检索知识库**
  - 读取客户档案、品牌调性库（禁止跳过）
4. **生成标题备选**
  - ⭐ 引用 `00-系统层/prompts/帮我生成标题备选.md`
  - 至少 3 个标题选项，直接在对话中呈现
  - 项目经理确认后选定标题
5. **按平台模板生成初稿**
  - 微信公众号：1500-3000字长文
  - 小红书：300-800字种草
  - 独立博客：SEO长文
  - ⭐ 文件名使用确认后的标题（去掉标点符号）
  - ⭐ 严格遵循 SOP-06 中的写作质量标准（开头三行让人停下来/让人恍然大悟的洞察/金句只留1-2句）
6. **生成对应配图**
  - ⭐ 配图未完成 = 草稿不完整，不得提交审核
  - 严格遵循 [SOP-06B-配图生成](./SOP-06B-配图生成.md) 中的流程和比例要求
7. **执行真人感自检**
  - ⭐ 执行 [SOP-06C-真人感检测](./SOP-06C-真人感检测.md)
  - ⭐ 总分必须≥90分，各维度必须≥16分
  - 任何维度出现❌/✅格式、无「我」字判断、书面语堆积 → 必须修改后才能提交
8. **提交合规审核**
  - 真人感检测合格后（总分≥90），提交SOP-07合规审核

### 输出物

每篇文章独立文件夹，配图与文章同级：

```
04-草稿/YYYY-MM-DD/[平台]/[文章标题]/
├── [文章标题].md         ← 确认后的标题为文件名
├── [文章标题]-v2.md      ← 审核修改版本
├── 00-cover.png          ← 封面图
└── 01-xxx.png           ← 内容配图（如有）
```

## 阶段六：合规审核（AI Agent + 审核人）

### AI 自动审核（三道防线）

**第一道：广告法红线扫描**


| 违禁词数量 | 结果    | 处理            |
| ----- | ----- | ------------- |
| 0个    | 🟢 绿灯 | 直接进入下一道       |
| 1-2处  | 🟡 黄灯 | AI自动替换，记录修改详情 |
| ≥3处   | 🔴 红灯 | 记录位置，打回重写     |


**第二道：平台风控预判**


| 风险场景     | 结果    | 处理          |
| -------- | ----- | ----------- |
| 无风险项     | 🟢 绿灯 | 进入下一道       |
| 1个低风险项   | 🟡 黄灯 | 标注，AI建议修改方案 |
| ≥1个中高风险项 | 🔴 红灯 | 标注风险点，打回重写  |


**第三道：品牌调性一致性**


| 检查结果         | 结果    | 处理        |
| ------------ | ----- | --------- |
| 全部通过         | 🟢 绿灯 | 进入待发布池    |
| 语调轻微偏离       | 🟡 黄灯 | AI润色，记录修改 |
| 品牌名错误 / 严重偏离 | 🔴 红灯 | 打回重写      |


### 审核人复核（必须执行）

1. 浏览全部待发布文章标题（快速确认无违禁词、客户名正确）
2. 每平台抽查 ≥1 篇全文（公众号查开头+配图横版+底部来源+署名；小红书查情绪开头+AI标签；博客查目录+关键词）
3. 重点全文复核：含数据/竞品对比/品牌背书的文章
4. 确认配图目录存在（`[标题]-imgs/`）
5. 标注最终发布状态

## 阶段七：发布执行（人工）

### 发布后48h数据复盘（必须执行）


| 平台    | 回收指标         |
| ----- | ------------ |
| 微信公众号 | 阅读量/在看数/分享数  |
| 小红书   | 点赞/收藏/评论/阅读量 |
| 独立博客  | 搜索展现/点击量     |


复盘结论记录到发布确认单，关键发现追加到 `01-知识库/04-用户记忆库/用户记忆与经验库.md`。

## 异常情况处理


| 异常          | 处理方式                       | 责任人   |
| ----------- | -------------------------- | ----- |
| 热点抓取失败      | 手动补充热点 / 使用备用选题库           | 人工    |
| 无热点入选       | 启动 `03-选题库/备用选题池/`         | 人工    |
| 热点过多（>20个）  | 按评分排序取 Top 15，超出部分标记"后续跟进" | AI    |
| AI创作质量下降    | 检查知识库是否更新 / 人设Prompt是否偏离 / SOP-06C真人感检测是否通过   | AI+人工 |
| 深度素材不足      | 补充抓取或降级为"跟进"类选题            | AI    |
| 文章被平台限流     | 检查合规审核日志 / 更新敏感词库          | 人工    |
| 品牌调性串味      | 确认当前客户档案 / 切换知识库上下文        | AI    |
| 红灯率超标（>20%） | 暂停，检查 SOP-06 质量标准          | 人工    |
| 客户名占位符残留    | 打回重写，检查 SOP-06 Step 7    | AI    |
| 配图未完成即提交    | 退回补图，参照 SOP-06B          | AI    |

## 流程检查清单

- 热点抓取：今日有新热点入库 / 无 → 启动备用选题池
- 素材库：入选热点≥3个来源 / 不足 → 补充抓取或降级
- 选题库：待创作选题积压≤3天 / 超期 → 标记废弃或重新评估
- 草稿：红灯率≤20% / 超标 → 暂停，检查质量标准
- 知识库：客户档案是最新的 / 过期 → 提醒项目经理更新

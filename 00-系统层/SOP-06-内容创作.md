## ⭐ 写作质量标准（必须遵守）

### 当前差距

对比运营研究社等优质账号，结合SOP-06C真人感检测结果，当前AI写作存在以下问题，按失分频率排序：

| # | 问题 | 典型表现 | 今日检测失分项 |
| -- | --- | -------- | ------------ |
| 1 | **个人视角缺失** | 有「我」但没有「我的判断」 | 7篇个人视角不及格，4篇低于10分 |
| 2 | **AI痕迹格式残留** | ❌/✅格式、步骤一/二/三 | 2篇出现❌/✅，3篇用步骤式小标题 |
| 3 | 洞察不够锐利 | 复述常识，没有恍然大悟 | 多数文章洞察有但不深 |
| 4 | 情绪温度不稳定 | 前半段情绪后半段冷 | 小红书篇最明显 |
| 5 | 书面语堆积 | 根据/意味着/这说明 | 多篇出现 |

### 核心心法（5条，新增第5条）

**1. 开头三行决定一切**

```
错误：5月3日，中央网信办开展专项行动...
正确：一觉醒来，9.8万个账号没了。这不是演习。
```

**2. 每段要有让人"啊"一下的时刻**

```
错误：数据显示，信任度高出40%
正确：信任度高出40%。换句话说，你越坦诚，读者越买账。
```

**3. 金句只留1-2句，放到最显眼位置**

到处都是金句等于没有金句。

**4. 案例要有故事性**

```
错误：王者荣耀、支付宝、京东分别做了响应
正确：48小时内三家巨头同时官宣，他们没有"创造"什么，只是接住了用户的热情。
```

**5. 「我」字出现不够，要让读者知道这篇文章是谁写的（新增）**

```
错误：我仔细想了想，发现这个趋势很有意思。
正确：我做私域3年，见过的翻车比我踩过的坑还多。这个趋势，恰恰是最容易被忽视的那种。

错误：有数据显示，情感型私域的LTV更高。
正确：我见过最极端的案例——有个品牌只做200人的情感型私域，转化率是大群的3倍。
数据是他们自己的销售告诉我的。
```

「我」字要出现，但更重要的是「我」后面跟的是判断、经历、数据，而不是空泛的「我研究过」「我分析」。

**禁止出现的格式（今日检测高频失分项）：**

- ❌/✅ 格式出现超过1次 → 直接影响情绪温度维度
- 「步骤一」「步骤二」「第一点」「第二点」作小标题 → 改成观点句
- 「根据xxx显示」「这意味着」「这说明」连续出现3次以上 → 换成「换句话说」「说白了」「其实」
- 结尾出现「以上是全文内容」「以上就是今天的分享」→ 换成引导互动或行动
- 「值得注意的是」「需要指出的是」→ 删掉，直接说

## AI写作流程

### 1. 明确任务

读取选题卡，确认：

- 当前服务客户
- 目标发布平台
- 文章切入角度
- ⭐ 素材引用清单

### 2. 读取热点素材库（⭐必须）

禁止在未读取素材库的情况下直接生成内容。

根据选题卡中的"素材引用清单"，读取对应素材文件。

### 3. 读取人设规范（⭐必须）

必须读取对应平台的写作规范：

```
读取路径：01-知识库/03-品牌调性库/[平台]/人设 Prompt.md
```

### 4. 检索知识库（RAG必做）

AI必须读取以下文件：

```
1. 客户档案库 → 01-知识库/01-客户档案库/[客户名]/品牌规范.md
2. 客户档案库 → 01-知识库/01-客户档案库/[客户名]/产品信息/产品矩阵.md
3. 合规风控库 → 01-知识库/02-合规风控库/违禁词表.md（若存在）
```

### 4.5. 生成标题备选（⭐必须）

在正式生成初稿前，必须先生成标题备选：

```
引用：00-系统层/prompts/帮我生成标题备选.md
生成：至少 3 个标题选项（标题A / 标题B / 标题C）
输出方式：直接在对话中呈现，供快速选择
```

**标题备选格式：**

```markdown
## 标题备选

**A. [标题文案]** ← 推荐
   理由：制造认知冲突，数字钩子强

**B. [标题文案]**
   理由：情绪共鸣，贴近受众焦虑

**C. [标题文案]**
   理由：悬念型，适合行业从业者
```

> 标题确认后，选定标题即为正式文件名（不含标点符号空格转义）。

### 5. 生成初稿

⭐ 使用确认后的标题作为文件名。文件名规则：

```
[标题].md（去掉标题中的标点符号和多余空格，不加客户前缀，不加日期）
```

**文件夹命名**：与文件名一致（无客户前缀、无日期）

**生成要求：**

- 开头制造认知冲突
- 每个段落要有记忆钉
- 案例要有故事性
- 要有灵魂金句
- 每个论点必须有原文素材支撑
- 引用时使用`>` 格式标注来源
- 底部列出所有引用来源

### 6. 生成配图（⭐配图未完成 = 草稿不完整）

> 详细流程见 [SOP-06B-配图生成](./SOP-06B-配图生成.md)

**重要约束：配图未生成完毕，不得提交审核。**

### 7. 真人感自检（⭐总分≥90才能提交SOP-07）

⭐ 执行 [SOP-06C-真人感检测](./SOP-06C-真人感检测.md)，总分必须≥90分，各维度必须≥16分，缺一不可提交。

**今日检测高频问题，创作时禁止：**

- ❌ ❌/✅ 格式出现超过1次
- ❌ 「步骤一/步骤二」「第一点/第二点」作小标题
- ❌ 「根据xxx显示」「这意味着」「这说明」连续出现3次以上
- ❌ 结尾出现「以上是全部内容」「以上就是今天的分享」
- ❌ 「值得注意的是」「需要指出的是」
- ❌ 全篇没有一句「我」的判断

**真人感自检清单（每项必查）：**

- 开头三行是否让人想停下来？（不是时间概述，不是背景介绍）
- 有没有一个让人恍然大悟的洞察？（不是复述常识）
- 有没有至少3处「我」的判断/经历/数据？（不是空泛的「我研究过」）
- 金句是否只留1-2句在显眼位置？（不是到处都是）
- 有没有删掉全部❌/✅格式？
- 结尾是不是让人想转发？（不是总结，不是「以上」）
- 语言是否口语化？（没有「根据」「意味着」「这说明」堆积）
- 所有AI模板痕迹（步骤一/引言/结论标注）是否已清除？

### 8. 提交合规审核

真人感自检合格后，提交SOP-07合规审核。

**提交前确认清单：**

- 草稿正文已生成
- 配图已全部生成（含封面图）
- 文件名使用确认后的标题
- 无「客户A」等占位符残留
- ⭐ 真人感检测总分≥90，各维度≥16

```

```

**结构模板**：

不要用「引言：制造冲突」「结论」「步骤」这类标注。文章本身就是文章，不是操作手册。

好的结构是：上来就说事，有画面，有冲突，然后一层层往下走。

```
开头：场景 + 冲突 + 悬念
中间：每个小节有一个核心观点，配合故事或案例
结尾：不是"总结"，而是一句让人记住的话
```

**不好的写法（AI感重）：**

```
## 引言：制造冲突

第一句：场景/事件描述（制造"不对劲"的感觉）
第二句：矛盾点揭示（让读者想知道为什么）
第三句：抛出核心问题（预告本文价值）
```

**好的写法（真实文章）：**

开头直接入戏：

> 母亲节那天，OPPO发了一条文案。几个小时后，高级副总裁降了两级。
>
> 快是快。但问责够快，就够了吗？

---

- **开头三行决定一切**：第一句就要让读者停下来，不能等

### 小红书 Agent

**定位**：种草分享、生活方式、真实体验

**⭐ 人设规范**：必须读取 `01-知识库/03-品牌调性库/小红书/人设 Prompt.md`

**素材来源**：必须读取热点素材库中的用户视角和真实案例

```
读取路径：02-热点池/热点素材库/YYYY-MM-DD/[热点标题]/
```

**结构模板**：

小红书不是大纲，是帖子。第一句话决定收藏率。

```
开头Hook：情绪要到位，"救命""真的""我以为"都好使
场景描述：让读者代入
个人经历/真实案例：只有你能说的视角
核心干货：最多3点，多了记不住
结尾：引导评论，不要写成"以上就是全部内容"
```

**不好的写法：**
```
## 第一部分：核心观点

1. xxx
2. xxx
3. xxx

以上就是我们今天的内容...
```

**好的写法：**
> 做了3年私域，我想说一句大实话：那些天天发优惠券的群，真的越来越难做了。
>
> 不是我说的，是数据说的。

---

**小红书写作要点：**

- **开头第一句**：要让人"啊"一下，不是"嗯"一下
- **不需要分点**：全部融进正文里，分点是大纲不是帖子
- **案例要具体**：不要"某品牌"，要"我认识一个博主"
- **结尾不要"以上就是全部内容"**：换成"你们有没有这种感觉？评论区说说"
- **标签要精准**：5个以内，不要堆砌，标签本身也是内容

**真实帖子示例：**

> ❌ 错误：
> 做私域要注意三点：1. 不要只发促销；2. 要建立情感连接；3. 要有独特人设。以上就是今天的分享～
>
> ✅ 正确：
> 做私域3年，我发现一个反直觉的事：发优惠券越勤快的群，死得越快。
>
> 用户薅完羊毛就跑了。你以为是文案不够好，换了文案还是一样。问题根本不在文案。问题在于——你做的根本不是"私域"，你做的是把用户圈进了一个更大的流量池，然后用促销的逻辑继续运营他们。

---

- **字数**：300-800字，多一个字都是罪过
- **语调**：真实、有温度、带个人风格，不是PPT
- **Emoji**：点缀即可，不要堆砌，表情是用来调情绪的，不是用来凑字的
- **⭐ 配图**：1-3 张（封面图必选，内容配图可选）
  - 封面图：`00-cover.png`，**3:4 竖版**（必选，简洁自然，少量文字）
  - 内容配图：`01-xxx.png`，3:4 或 1:1（真实场景/对比图）
- **⭐ 配图未完成 = 草稿不完整，不得提交审核**
- **配图存储**：`[文章标题]/`（与文章同级）
- **⭐ 写作要求**：必须从热点素材库中引用真实用户声音或案例，增强可信度

**Hook 示例**：

- "救命！这套方法让我 1 个月涨粉 5000"
- "做运营 3 年，我发现了一个反直觉的真相..."
- "真的！用了这个工具效率提升 3 倍"

**小红书专属自检（额外执行）：**

- 开头第一句是否能让人停下来？（不是问句开头+理性分析）
- 全篇语气是否统一？（不要前半段情绪化、后半段变分析师）
- 结尾有没有引导互动？（不是"以上就是全部内容"）
- 标签是否精准、是否少于5个？
- 有没有一个"只有你能说"的个人视角？
- 有没有用 ❌/✅ 这种AI痕迹明显的格式？（删掉，改成自然叙述）
- 有没有直接用"如果xxx"的设问句当小标题？（改成陈述句）

### 独立博客 Agent

**定位**：SEO 长尾流量、专业深度、搜索引擎友好

**⭐ 人设规范**：必须读取 `01-知识库/03-品牌调性库/独立博客/人设 Prompt.md`

**素材来源**：必须读取热点素材库中的背景资料和深度解读

```
读取路径：02-热点池/热点素材库/YYYY-MM-DD/[热点标题]/
```

**结构模板**：

独立博客不是论文，是给行业人看的深度文章。目录可以有，但正文要像杂志专题，不像教科书。

```
H1：主标题，含核心关键词
> 导读（60-100字，让人知道值不值得读）

正文章节：用观点推进，不是用小点堆砌
FAQ：根据读者实际困惑来写，不是凑数
```

**不好的写法：**

```
## 一、背景与概述

### 1.1 行业背景
...
### 1.2 定义
...
## 二、核心方法
...
## 三、总结
```

**好的写法：**

> 开头直接入题，不需要"随着时代发展"这种废话。背景信息融进第一段里，让读者知道这篇文章在解决什么问题。

---

**独立博客写作要点：**

- **H2章节用观点做标题**：不是"背景""方法""总结"，而是"OPPO这次翻车翻在哪""内容审核的三层漏斗"
- **FAQ是实打实的**：写读者真正会问的问题，不是凑5个FAQ装完整
- **段落要长一些**：独立博客的读者愿意读长文，不像公众号那样跳读
- **结尾可以比公众号更从容**：可以有一段"写给同行的话"，更真实

---

- **字数**：1500-5000字（SEO优化）
- **语调**：严谨、客观、有料，不是说明书
- **SEO 要点**：关键词布局、内链结构化数据
- **⭐ 配图**：2-5 张（封面图必选 + 内容配图 1-4 张）
  - 封面图：`00-cover.png`，16:9 横版（必选）
  - 内容配图：`01-xxx.png` / `02-xxx.png`，16:9（信息图/流程图/案例图）
- **⭐ 配图未完成 = 草稿不完整，不得提交审核**
- **配图存储**：`[文章标题]/`（与文章同级）
- **⭐ 写作要求**：必须从热点素材库中引用背景资料和深度解读，确保内容的权威性和可读性

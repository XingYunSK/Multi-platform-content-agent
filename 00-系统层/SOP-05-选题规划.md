# 选题规划

> 从热点简报到选题卡的标准生产流程
>
> **重要更新（2026-05-14）**：本 SOP 新增灵感库选题入口（SOP-05B）。
> 每日选题时，先判断选题来源，再决定执行哪个流程。

---

## 零、选题来源判断

> **每日选题前，必须先判断选题来源。**

```
选题来源判断流程：

IF 用户已指定选题来源
  → 按指定来源执行对应分支

IF 用户未指定选题来源
  → 向用户确认：
    [A] 热点驱动 → 执行 SOP-03 热点抓取 → SOP-05 选题规划
    [B] 灵感库选取 → 执行 SOP-05B 灵感库深度挖掘
    [C] 固定栏目 → 读取当月固定栏目计划
    [D] 备用选题池 → 读取 03-选题库/备用选题池/
    [E] 客户指定 → 直接进入选题卡生成
```

---

## 零B、灵感库选题流程（SOP-05B）

> 详见 `00-系统层/SOP-05B-灵感库深度挖掘.md`

当用户选择灵感库选题时，执行以下流程：

```
1. 读取灵感库索引（03-选题库/灵感库.md）
2. 按目录列出可激活灵感
3. 用户选择灵感编号
4. 深度信息挖掘（搜索收集相关信息）
5. 生成选题卡
6. 更新灵感库状态
```

**关键原则**：

- 灵感库选题必须执行深度挖掘，搜索信息不完整不得进入选题卡生成
- 灵感库入口：分支B，跳转 SOP-05B

## 一、内容支柱体系（第一层）

> 支柱决定"为什么写"，决定内容的核心目的和情绪类型。

> **核心原则**：情绪型（P1）和 IP 名人堂（P2）是现有系统的最大缺口，必须补足占比。

### 支柱 × 热点快速映射

```
IF 热点是工具/产品发布
  → P1-B 震撼型（如"疯了！XX 竟然 XX"）
  → P3 配合实操指南

IF 热点涉及 IP 人物
  → 立即激活 P2 IP 名人选题
  → 插入当周 P2 档期（周三或周四）

IF 热点是数据/榜单
  → P1 焦虑型（如"你的同行已经在 XX"）
  → P3 配合方法论

IF 热点是负面事件（品牌翻车/平台封号）
  → P1 代入型（如"XX 踩的坑，你也正在踩"）
  → P3 配合避坑指南

IF 热点是法规/政策
  → P3 方法论型（如"官方明确了，XX 以后这样做"）
  → P1 焦虑型预热（如"XX 以后要注意了"）
```

## 二、选题判断标准（第二层）

> 在支柱框架内，评估具体选题的优先级。

### 评分矩阵


| 维度    | 权重  | 评估问题            |
| ----- | --- | --------------- |
| 热度    | 30% | 这个话题近期有多少人在关注？  |
| 客户关联  | 30% | 能服务≥1 个客户吗？     |
| 多平台适配 | 25% | 能转化为≥2 个平台的内容吗？ |
| 素材丰富度 | 15% | 有足够的素材支撑吗？      |


**总分 ≥ 70** → 进入「热榜优先级」
**总分 40-69** → 进入「常规选题」
**总分 < 40** → 记录灵感池

### 选题类型归属（旧体系 A/B/C/D/E 仍然保留，作为支柱的子分类）


| 类型  | 名称     | 说明        | 当日上限       |
| --- | ------ | --------- | ---------- |
| A   | 热点蹭流量  | 热点驱动，时效性强 | ≤ 当日选题 50% |
| B   | 案例拆解   | 围绕案例提炼方法论 | 不限         |
| C   | 方法论/教程 | 系统性操作指南   | 不限         |
| D   | 行业观点   | 行业趋势/政策解读 | 不限         |
| E   | 客户案例   | 真实合作案例展示  | 不限         |


**判断规则：** 热点发生时优先 A 型，但每个 A 型必须判断能否扩展为 B 或 C 型。

## 三、选题卡生成流程

### 第一步：读取月度规划（必读）

读取 `03-选题库/选题规划总表`，确认当月是否有已规划的固定选题。

### 第二步：读取热点日报

AI 读取当日热点简报，提取 Top 3-5 热点。

### 第三步：确定支柱类型

根据热点性质，对照「支柱 × 热点快速映射」，确定内容支柱类型（P1/P2/P3）。

### 第四步：读取深度素材库（关键）

对每个热点，读取对应的素材库文件夹，禁止跳过。

### 第五步：套用平台选题模板

读取 `03-选题库/各平台选题模板.md`，根据支柱类型和目标平台，选取对应标题模板，生成 3 个以上标题备选。

### 第六步：生成多平台分发方案

对每个强关联热点，生成多平台分发方案：

```markdown
### [客户名] - 微信公众号
- **标题**：《[标题]》
- **支柱**：P1/P2/P3
- **类型**：[A/B/C/D/E]
- **领域**：[来自选题主题库]
- **切入点**：[切入角度 + 差异化说明]
- **素材引用**：
  - 官方视角 → 引用"原文素材1-[来源].md"
  - 行业数据 → 引用"原文素材2-[来源].md"
  - 背景分析 → 引用"背景资料.md"
- **字数**：2000字

### [客户名] - 小红书
- **标题**：[标题]
- **支柱**：P1（情绪型主战场）
- **切入角度**：[情绪型切入]
- **字数**：500-800字

### [客户名] - 独立博客（可选）
- **标题**：[SEO 优化版标题]
- **支柱**：P3
- **字数**：2000-4000字
```

### 第七步：项目经理审核

- 确认支柱类型（P1/P2/P3）
- 确认选题方向
- 确认切入角度
- 确认标题备选
- 确认素材深度

## 四、选题卡质量标准

- 每个热点至少分配 1 个客户
- 每个客户×热点至少覆盖 1 个平台
- **新增：必须标注内容支柱（P1/P2/P3）**
- 标注了内容类型（A/B/C/D/E）
- 确认选题落入选题主题库的某个领域
- **新增：必须从用户视角出发（读者第一反应是"这和我有什么关系"）**
- 有差异化角度说明（vs 竞品）
- 标题有吸引力（套用模板后自检）
- 切入点与品牌调性一致
- 字数符合平台规范
- 每个选题包含素材引用说明

## 六、灵感池管理

> 灵感池已升级为独立 SOP，详见 SOP-05B。

总分 < 40 的选题进入灵感池，不丢弃。


| 触发时机        | 动作                       |
| ----------- | ------------------------ |
| 每日（用户选择分支B） | 读取灵感库，列出可激活灵感供用户选择       |
| 每周五整理       | 从灵感池中筛选可激活选题，评估是否升级为正式选题 |
| 每月末         | 从灵感池升级正式选题（评分≥70）        |
| 每季度         | 归档过时灵感（>90天未激活）          |


灵感库位置：`03-选题库/灵感库.md`

## 七、OPC 复用规则（跨平台内容）

> One Piece Content——一次创作，多平台分发。

**核心原则**：一篇内容 = 1 个核心洞察 + 3 个平台版本


| 平台    | 篇幅          | 核心调整                  |
| ----- | ----------- | --------------------- |
| 微信公众号 | 1500-3000 字 | 深度分析 + 方法论 + 专业调性     |
| 小红书   | 300-800 字   | 情绪共鸣 + 个人视角 + 真实感     |
| 独立博客  | 1500-5000 字 | SEO 优化 + 步骤指南 + 关键词布局 |


**触发条件**：当选题同时覆盖多个平台时，必须执行 OPC 复用规则。

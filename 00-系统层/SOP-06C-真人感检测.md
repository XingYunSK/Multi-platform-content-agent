# 真人感检测

> 内容提交合规审核前的预审层。专门检测「读起来像不像真人写的」，解决AI写作痕迹问题。
>
> **核心目标：** 一篇内容在发布前，必须通过真人感检测。**总分低于90分，不进入合规审核，直接打回修改。**

---

## 定位说明

SOP-06负责「怎么写」，SOP-06C负责「写得像不像人」。

这不是合规检查，不看违禁词、不看数据来源、不看品牌调性——那些是SOP-07的事。

SOP-06C只回答一个问题：**这篇读起来像不像真人写的？**

---

## 整体流程

```
初稿完成
  ↓
真人感检测（SOP-06C）
  ↓
[总分 ≥ 90] → 进入合规审核（SOP-07）
[总分 < 90] → 打回修改，记录问题
  ↓
修改后复检 → 再次通过SOP-06C → 合格后进入SOP-07
```

| #   | 维度    | 满分  | 及格线 | 检测重点         |
| --- | ----- | --- | --- | ------------ |
| 1   | 开头钩子力 | 20  | 16  | 第一句话是否让人停下来  |
| 2   | 情绪温度  | 20  | 16  | 读起来有温度还是冷冰冰  |

**总分 100分，≥90分合格，<90分打回修改。**

## 维度一：开头钩子力（20分）

### 检测标准


| 分值     | 表现                             |
| ------ | ------------------------------ |
| 18-20分 | 第一句话就有画面感或冲突，让人停不下来            |
| 14-17分 | 第一句话还行，但需要往下读两三行才能抓住人          |
| 10-13分 | 开头平淡，需要读到第二段才有感觉               |
| 5-9分   | 开头像是从网上抄来的概述，没有画面              |
| 0-4分   | 开头就是「随着xxx」「xxx已经xxx」「今天我们来讲讲」 |


### AI痕迹检测项（发现即扣分）

- 开头第一句是时间概述（「5月11日」「2026年」「今天上午」）
- 开头是背景介绍（「在xxx背景下」「随着xxx的发展」）
- 开头是设问但语气冷淡（「你是否曾经xxx？」）
- 开头用了「我们来聊聊」「今天分享」等汇报式开头
- 开头没有任何场景感，直接上结论

### 典型问题定位与修改建议

```
问题类型A：时间概述型开头
原文：5月11日，黄仁勋在CMU毕业典礼上发表演讲，说了一句话刷屏全网。
修改：英伟达CEO黄仁勋，身价逼近1860亿美元——他在毕业典礼上说了一句话，全网都在转。
      但我读完他的演讲全文，发现那句话只是皮毛。

问题类型B：背景介绍型开头
原文：在AI快速发展的今天，很多人都在焦虑AI会不会取代自己的工作。
修改：朋友最近跟我抱怨，说他公司刚上了一套AI系统，他每天都在担心自己会不会被优化。
      我说你与其担心这个，不如先想清楚一件事——

问题类型C：冷淡设问型开头
原文：你有没有发现，很多品牌的私域越做越累？
修改：私域建了5000人，每天发消息、推产品、做活动——但用户要么不回复，要么回复了也不下单。
      换了三版文案，效果还是一样。问题根本不在文案。
```

## 维度二：情绪温度（20分）

### 检测标准


| 分值     | 表现                          |
| ------ | --------------------------- |
| 18-20分 | 读的时候能感觉到「有个真实的人在想这件事」，情绪有起伏 |
| 14-17分 | 大部分段落有温度，偶尔有几段偏冷            |
| 10-13分 | 整体偏理性，像分析报告，但不失真            |
| 5-9分   | 像教科书，像说明书，读完没有任何情绪波动        |
| 0-4分   | 全篇AI生成感极强，一看就是模板填充          |


### AI痕迹检测项（发现即扣分）

- 全篇用了3个以上「这意味着」「这说明」「这揭示了」
- 连续出现「首先/其次/最后」「第一/第二/第三」等公式化连接词
- 所有段落结构完全相同（观点+数据+结论，一模一样的三板斧）
- 没有任何感叹句，全部是陈述句
- 用了「姐妹们」「家人们」但语气依然冷淡（称呼和内容割裂）
- 出现了「以上」「综上所述」「总的来说」等总结式收尾
- 用了「值得注意的是」「需要指出的是」等官话连接词
- ❌/✅ 格式出现了2次以上（这是AI痕迹最强的格式之一）

### 典型问题定位与修改建议

```
问题类型A：❌/✅ 格式滥用
原文：
❌ 第一个坑：觉得人越多越好
✅ 做法：精简到几百个核心用户

修改：
我之前也犯过这个错。加了5000人进群，以为「人多力量大」。
结果呢？我连群里的人名都记不住，他们更记不住我。
后来我把群精简到三百人，反而转化率翻了一倍。
道理很简单——你能记住多少人，你就能服务好多少人。

问题类型B：公式化连接词堆砌
原文：
首先，情感型私域的核心是建立信任。
其次，信任的建立需要时间。
最后，信任会带来自然转化。

修改：
做私域的人都知道，信任比流量值钱。
但知道归知道，真做起来的人都急。恨不得今天拉群，明天就成交。
其实从陌生到信任，正常需要90天以上。这不是玄学，是规律。
你省掉这90天，信任就建不起来，后面的转化反而更慢。

问题类型C：称呼和内容割裂
原文：
姐妹们！你们有没有发现，私域建了5000人……
（然后开始冷冰冰地列数据、讲方法论）

修改：
做了3年私域，我有个特别扎心的发现——
那些天天在群里发优惠券的，反而死得最快。
不是我瞎说，是我自己用钱买来的教训。
```

## 维度三：个人视角（20分）

### 检测标准


| 分值     | 表现                        |
| ------ | ------------------------- |
| 18-20分 | 有且仅有一个明确的「我」在说话，有真实的经历或判断 |
| 14-17分 | 有个人视角，但偶尔会被素材引用淹没         |
| 10-13分 | 有个人声音，但不够鲜明，读不出「这个人才会这么说」 |
| 5-9分   | 整篇都是素材的转述，没有「我」的判断        |
| 0-4分   | 通篇没有一句话是「我」说出来的，全是别人说的    |


### AI痕迹检测项（发现即扣分）

- 「我」字从未出现，或只在结尾客套话里出现一次
- 全篇只有「素材说」「数据显示」「专家观点」，没有「我认为」
- 用了「有人说」「也有观点认为」，但都是素材里的观点，没有作者自己的判断
- 写案例时全是「XX品牌做了XX」，没有「我见过XX」「我经历过XX」
- 结尾是「以上是本文的全部内容」「以上就是今天的分享」等没有个人声音的客套话

### 典型问题定位与修改建议

```
问题类型A：素材淹没个人声音
原文：
英语博主变现的核心在于信任建立。用户为什么要为陌生人的课程付费？
因为专家观点认为，信任是付费的前提……

修改：
英语博主变现这件事，我研究了很多案例。
有人说是因为内容好，有人说是因为定位准。
但我仔细看了十几个成功案例，发现他们都有一个共同点——用户付费前，
已经把这个博主当成了「懂我的朋友」，而不是「卖课的」。
这个转变，才是关键。

问题类型B：没有个人判断
原文：
Sega的CEO同意了黄仁勋的请求。这说明诚实和谦逊有时会得到善意回应。

修改：
说实话，我读到这段的时候愣了一下。
黄仁勋当时是什么处境？英伟达技术失败，公司快要倒闭，他飞到日本去道歉，
求对方解除合同还继续付款。换作大多数人，早就被羞辱感淹没了。
但他去了，而且对方同意了。
这背后不是技巧，是信任。商业世界里，诚实有时候反而是最好的策略。
```

## 维度四：洞察锐度（20分）

### 检测标准


| 分值     | 表现                   |
| ------ | -------------------- |
| 18-20分 | 至少有1处让人「读到这才恍然大悟」的时刻 |
| 14-17分 | 有1-2处有价值的观点，但可以更锐利   |
| 10-13分 | 有观点但不反直觉，读完感觉「我知道这些」 |
| 5-9分   | 全篇在复述常识或素材，没有新东西     |
| 0-4分   | 整篇就是热点事件的扩写，没有任何个人解读 |


### AI痕迹检测项（发现即扣分）

- 「这说明」「这意味着」「这告诉我们」出现了3次以上（说明只有复述没有洞察）
- 所有观点都是正向推理，没有反直觉洞察（「越X，Y反而……」型）
- 金句太多，到处都是让人眼前一亮的话，反而没有一句让人记住
- 结尾的观点和开头没有拉开距离，读完感觉「还是那些道理」
- 用了大量「值得注意」「需要关注」「值得关注」但没有说清楚为什么值得关注

### 典型问题定位与修改建议

```
问题类型A：只有复述没有洞察
原文：
黄仁勋说AI不会取代你，但会用AI的人会取代你。这意味着我们要学会使用AI。

修改：
黄仁勋说AI不会取代你，但会用AI的人会取代你。
这句话看起来是鼓励大家学AI。
但他紧接着说的那句话，才是真正扎心的——
「我们希望自己的孩子被AI增强，还是被那些被AI增强的人甩在后面？」
这道选择题，没有选项B。
你要么被增强，要么被淘汰。

问题类型B：金句泛滥失去焦点
原文：
价格可以被复制，促销可以被复制，但信任不能被复制。
功能型私域是快钱逻辑，情感型私域是慢钱逻辑。
私域的终局不是流量池，而是情感共同体。

修改：
价格可以被复制，促销可以被复制，但信任不能被复制。
这一句话就够了。
其他的金句，都是这句话的变体，说再多也走不出这个圈。
```

## 维度五：语言自然度（20分）

### 检测标准


| 分值     | 表现                         |
| ------ | -------------------------- |
| 18-20分 | 读出来顺口，像一个人在跟你说话，没有书面语的不自然感 |
| 14-17分 | 基本自然，有1-2处读起来拗口            |
| 10-13分 | 有书面语感但不严重，读完不觉得假           |
| 5-9分   | 多处书面语/官话，读起来像工作报告          |
| 0-4分   | 通篇书面语，读一句停一下，不知道在跟谁说话      |


### AI痕迹检测项（发现即扣分）

- 「根据」「依据」「通过以上分析」「综合来看」出现了2次以上
- 「首先/其次/最后」「第一/第二/第三」结构出现2次以上
- 用了「在一定程度上」「相对而言」「总体而言」等模糊词
- 段首用了「因此」「所以」「由此可见」等生硬连接
- 出现了「值得注意的是」「需要特别说明的是」等套话
- 句子平均长度超过30字，且大量使用从句
- 读一遍发现没有任何感叹句、没有口语化表达

### 典型问题定位与修改建议

```
问题类型A：书面语堆积
原文：
根据相关数据显示，情感型私域的用户生命周期价值（LTV），
是功能型私域的3至5倍。这意味着品牌应该重视情感连接。

修改：
一个有意思的数据：情感型私域的用户LTV，是功能型的3到5倍。
换句话说，你用3个月建的关系，比别人用促销砸3年的转化还稳。

问题类型B：生硬连接词
原文：
OPPO的反应速度很快。然而，问责只是结果，并不是原因。

修改：
OPPO的反应速度确实快，当天就发了公告。
但我想问一句：问责够快，就够了吗？

问题类型C：从句套从句
原文：
在内容审核层面，我们认为，多元视角的参与是确保内容质量，
以及避免类似OPPO此次翻车事件再次发生的必要条件。

修改：
OPPO这次文案能流出来，说明审的人也都觉得没问题。
问题就出在这里——如果审的人都是同一个背景，
他们对这句话的敏感度，自然就低。
```

## 打回标准

以下情况直接判定为不合格（≤40分），打回修改，不进入SOP-07：

- ❌ 出现了❌/✅格式 → 直接-10分
- ❌ 全篇没有「我」字出现 → 直接-10分
- ❌ 开头第一句是时间概述或背景介绍 → 直接-5分
- ❌ ❌/✅格式 + 无个人视角 + 书面语堆积 三项同时出现 → 直接打回，不评分
- ❌ 读起来完全像模板填充 → 直接打回，不评分

## 与SOP-07的关系


| 检查项            | 负责SOP              |
| -------------- | ------------------ |
| 违禁词、数据准确性      | SOP-07第一道（广告法扫描）   |
| 平台风控、品牌调性      | SOP-07第二、三道        |
| 热点素材呼应、差异化     | SOP-07第四道（7维度质量评分） |
| **读起来像不像真人写的** | **SOP-06C（本文）**    |


SOP-06C是进入SOP-07的门槛，两套检查并行，缺一不可。

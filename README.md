>
> 面向代运营公司 / 中小品牌 / KOL，一套系统服务 N 个客户

## 快速开始

**第一步：** 阅读 `00-系统层/SOP-00-系统总览.md`

**第二步：** 配置知识库（至少一个客户档案）

- `01-知识库/01-客户档案/[客户名]/品牌规范.md`

**第三步：** 启动每日工作流

- 在 Cursor/Cursor 中说"帮我开始今日SOP"
- 或手动阅读 `00-系统层/SOP-01-每日工作流.md`

---

## 核心原则

- **合规优先**：任何内容必须经过合规审核，不得跳过
- **RAG防幻觉**：AI写作前必须检索客户知识库
- **多客户矩阵**：同一热点，多客户差异化表达
- **数据驱动**：发布数据回流，持续优化选题策略

## 五、标题自检工具

> 生成标题后，用以下问题逐一检查，不通过则修改。

### 微信公众号标题自检

```
1. 「谁」在看？（目标人群是否清晰）
2. 「什么好处/痛点」？（用户能获得什么）
3. 「为什么现在」？（时效性是否成立）
4. 「凭什么信你」？（数字/人物/机构是否可信）
5. 3 秒内能读完吗？（长度是否合适）
```

### 小红书标题自检

```
1. 有 Emoji 吗？（1-3 个，自然融入）
2. 有具体数字吗？（增加可信度）
3. 有「我」的视角吗？（真实感）
4. 结尾有「钩子」吗？（引发互动）
5. 能引发「说的就是我」的感觉吗？（代入感）
```

### 独立博客标题自检

```
1. 主关键词在标题前 30 字吗？（SEO 友好）
2. 包含年度/版本号吗？（时效性信号）
3. 包含「完整」「指南」等搜索词吗？（高搜索意图）
4. 比搜索结果中其他标题更有价值吗？（竞争意识）
```

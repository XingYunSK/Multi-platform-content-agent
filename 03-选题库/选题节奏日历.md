## 五、热点快速响应机制

> 热点发生时，快速判断是否值得蹭，以及如何切入。

### 热点分级响应

| 热点级别 | 判断标准 | 响应时间 | 发布形式 | 档期调整 |
|----------|----------|----------|----------|----------|
| P0（重大热点） | 全网刷屏/平台热搜前 3/涉及 IP 人物 | 2 小时内启动，24 小时内发布 | 当周插入，临时调整 | 原定周二/周四 P1 替换为热点选题 |
| P1（重要热点） | 行业热搜/垂直领域关注度高 | 4 小时内启动，48 小时内发布 | 当周插入或次周首发 | 与原定选题合并或替换 |
| P2（常规热点） | 有话题性但非刷屏级 | 次日启动，72 小时内发布 | 次周档期 | 保持原计划不变 |

### 热点 × 支柱快速映射

```
热点发生时，快速判断切入点：

IF 热点是工具/产品发布
  THEN → P1-B 震撼型标题（如"疯了！XX 竟然 XX"）
        + P3 配合实操指南

IF 热点是人物动态（马斯克/梁文峰/余承东等）
  THEN → 立即激活 P2 IP 名人选题
        + 插入当周 P2 档期（周三或周四）

IF 热点是数据/榜单
  THEN → P1 焦虑型（如"你的同行已经在 XX"）
        + P3 配合方法论

IF 热点是负面事件（品牌翻车/平台封号）
  THEN → P1 代入型（如"XX 踩的坑，你也正在踩"）
        + P3 配合避坑指南

IF 热点是法规/政策
  THEN → P3 方法论型（如"官方明确了，XX 以后这样做"）
        + 配合 P1 焦虑型预热（"XX 以后要注意了"）
```

## 六、选题黑名单

> 以下类型选题不进入规划，除非有重大新闻由项目经理特批。

| 类型 | 原因 | 替代方向 |
|------|------|----------|
| 纯蹭热度无实质内容 | 损伤品牌调性 | 热点 + 方法论组合 |
| 纯负面/恐慌煽动 | 读者反感，无法带来正向信任 | 焦虑 + 可执行出路 |
| 竞品对比踩踏 | 违反品牌规范 | 行业趋势中性分析 |
| 夸大效果承诺 | 违反广告法 | 有数据支撑的效果案例 |
| 无来源的"内幕消息" | 风险高 | 引用权威媒体报道 |

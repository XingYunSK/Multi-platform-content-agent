## 1. 系统工作原理

### AI Agent + Obsidian 的分工

| 组件 | 负责 |
|------|------|
| **Cursor Agent（AI）** | 执行所有创作逻辑：抓取、分析、生成、审核 |
| **Obsidian（本地知识库）** | 存储结构化文件：SOP / 知识库 / 素材 / 草稿 |
| **GitHub** | 版本控制 + 团队同步 |

AI Agent 每次执行任务时，**读取 Obsidian 文件作为上下文**，将生成结果**写回 Obsidian**，形成闭环。

### 七阶段数据流

```
01 热点抓取（SOP-03）
    ↓ [日报写入] 02-素材库/日报/
02 深度素材挖掘（SOP-04）
    ↓ [素材写入] 02-素材库/素材库备份/
03 选题规划（SOP-05）
    ↓ [选题卡写入] 03-选题库/选题日报/
04 内容创作（SOP-06）
    ↓ [草稿写入] 04-创作/[日期]/[平台]/
04B 配图生成（SOP-06B）
    ↓ [图片写入] 同上文件夹
05 审核发布（SOP-07）
    ↓ [发布记录写入] 06-发布/
    ↓ [数据归档] 01-知识库/04-用户记忆库/
```

## 2. 每日工作流详解

### 启动方式

在 Cursor 中打开本仓库，对 AI 说：

```
帮我开始今日SOP
```

AI 将按顺序执行 SOP-01 定义的步骤，**每步完成后主动确认**，你可以在中途干预或调整。

### 每日标准流程（手工执行版）

如果你想手动控制每一步：

**Step 1：早会（5分钟）**

```
今天状态怎么样？
```

→ AI 输出系统健康度报告，包括：热点入库数 / 素材完整性 / 选题积压 / 待发布

**Step 2：热点确认（10分钟）**

阅读 `02-素材库/日报/今日热点简报-YYYY-MM-DD.md`，确认今日入选热点

**Step 3：素材确认（5分钟）**

检查 `02-素材库/素材库备份/YYYY-MM-DD/[热点]/`，确保入选热点都有 ≥3 来源支撑

**Step 4：选题确认（10分钟）**

阅读 `03-选题库/选题日报/`，选择今日写作选题

**Step 5：创作（按需）**

```
帮我写一篇[小红书/公众号]，[选题名]，客户是[客户名]
```

**Step 6：配图（按需）**

```
帮我生成这篇文章的配图
```

**Step 7：审核（AI 自动）**

AI 按 SOP-07 执行四道审核，打回不符合的内容

**Step 8：发布（按需）**

发布后手动或通过 AI 填写 `06-发布/发布日志/今日发布日志.md`

## 3. 知识库配置

### 3.1 新建客户档案

在 `01-知识库/01-客户档案库/` 下创建以客户名命名的文件夹：

```
01-知识库/01-客户档案库/[客户名]/
├── 品牌规范.md           ← 必填
├── 产品矩阵.md           ← 必填
├── 竞品分析.md
├── 人群画像.md
├── 推广目的.md
└── 内容禁忌.md
```

### 3.2 品牌规范模板

```markdown
# [客户名] 品牌规范

## 品牌定位
[一句话描述品牌在市场中的位置]

## 核心卖点（TOP 3）
1. [卖点一]
2. [卖点二]
3. [卖点三]

## 目标人群
[年龄/职业/痛点/需求]

## 品牌调性
- 语言风格：[正式/活泼/专业/亲切...]
- 视觉风格：[配色/字体/图片风格]
- 内容禁区：[明确说明不能写的内容]

## 竞品差异化
[相比竞争对手的核心优势]

## 传播主题
[品牌长期传播的核心主题/口号]
```

### 3.3 合规风控库

路径：`01-知识库/02-合规风控库/`

每个平台需单独配置：
- `微信公众号违禁词.md`
- `小红书违禁词.md`
- `独立博客违禁词.md`

### 3.4 品牌调性库

路径：`01-知识库/03-品牌调性库/`

每个平台每个客户需单独配置 Prompt：
- `微信公众号/品牌A.md` → 公众号风格人设
- `小红书/品牌A.md` → 小红书种草风格
- `独立博客/品牌A.md` → SEO 长文风格

## 4. 多客户管理

### 切换客户

在 AI 对话中明确指定：

```
帮我开始今日SOP，客户是[客户名A]
```

或同时执行多客户：

```
帮我开始今日SOP，客户是[客户名A]和[客户名B]
```

### 多客户矩阵输出

同一热点，针对不同客户的输出差异：

| 维度 | 客户A | 客户B |
|------|-------|-------|
| 切入角度 | 产品功能 | 行业洞察 |
| 风格调性 | 亲切种草 | 专业深度 |
| 案例引用 | 消费者故事 | B端案例 |
| CTA | 立即购买 | 联系我们 |

## 5. 热点抓取与素材挖掘

### 5.1 热点来源

| 来源 | 说明 | 数据类型 |
|------|------|---------|
| AI HOT 精选 | AI/大模型行业 | 资讯/论文/产品 |
| 小红书热搜 | C端消费品趋势 | 话题/热词 |
| 微信公众号爆款 | 长文传播 | 话题/角度 |
| 行业垂直媒体 | 特定行业 | 深度分析 |

### 5.2 深度素材挖掘四步法

```
Step 1: 多源采集（≥3个独立来源）
Step 2: 交叉验证（信息一致性检查）
Step 3: 深度分析（背景/原因/影响/延伸）
Step 4: 素材整理（结构化输出：背景+观点+数据+案例）
```

## 6. 内容创作

### 6.1 平台内容规格

| 平台 | 字数 | 风格 | 配图 |
|------|------|------|------|
| 微信公众号 | 1500-3000字 | 深度/专业 | 3-6张信息图 |
| 小红书 | 300-800字 | 种草/亲切 | 封面+3-9张图 |
| 独立博客 | 2000-5000字 | SEO/长文 | 1-3张封面 |

### 6.2 文章质量标准（SOP-06）

- 标题有吸引力（点击率预判）
- 开头 100 字抓住注意力
- 核心观点有数据/案例支撑
- 结尾有明确 CTA
- 通过全部合规审核

## 7. 配图生成

### 触发方式

```
帮我生成这篇文章的配图
```

### 配图类型

| 类型 | 说明 |
|------|------|
| 封面图 | 吸引眼球，一图说清主题 |
| 信息图 | 数据/流程/对比结构化呈现 |
| 场景图 | 增强代入感的生活场景 |

### 配图规范

- 风格与品牌调性一致
- 统一配色体系
- 文字清晰可读
- 无版权风险

## 8. 审核发布

### 四道审核防线

| 防线 | 检查内容 | 触发条件 |
|------|---------|---------|
| 第一道：违禁词 | 违禁词/敏感词过滤 | 所有内容 |
| 第二道：平台红线 | 各平台政策合规 | 各平台专属 |
| 第三道：品牌规范 | 调性/卖点/禁忌一致性 | 所有内容 |
| 第四道：质量评分 | 原创度/可读性/吸引力 | 所有内容 |

### 发布平台

| 平台 | 发布频率建议 |
|------|------------|
| 微信公众号 | 每周 3-5 篇 |
| 小红书 | 每周 5-7 篇 |
| 独立博客 | 每周 1-2 篇 |

## 9. 数据复盘与优化

### 周度复盘

```
请帮我做本周内容数据复盘
```

AI 汇总发布数据，分析：
- 哪类选题表现好
- 哪个平台效果最好
- 哪些内容需要优化

### 用户记忆库更新

复盘后将关键发现写入：

```
01-知识库/04-用户记忆库/
├── 爆款规律.md
├── 踩坑记录.md
└── 平台算法变化.md
```

## 10. 故障排查

### 热点抓取失败

```
→ 自动切换至选题库备用选题池
→ 手动触发：「挖掘[具体话题]热点」
```

### 素材不足（<3来源）

```
→ 降低该热点优先级，跟进式处理
→ 或手动触发：「帮我深度挖掘[话题]」
```

### AI 创作质量下降

```
→ 检查知识库是否过期 → 更新客户档案
→ 检查素材完整性 → 补充素材
→ 触发：「用[具体方式]优化这篇文章」
```

### 审核红灯过多

```
→ 检查违禁词库是否过期
→ 检查品牌规范是否明确
→ 超标率>20%暂停，检查 SOP-06 质量标准
```

## 🎯 用户写作风格偏好

### 内容调性


| 维度        | 偏好设置             |
| --------- | ---------------- |
| **专业度**   | 高（行业专家视角，但不失亲和）  |
| **情绪温度**  | 中高（有温度感，但避免过度煽情） |
| **信息密度**  | 高（干货满满，拒绝废话）     |
| **口语化程度** | 中（专业但不晦涩，适当用比喻）  |


### 结构偏好

- ✅ 喜欢用「---」作为章节分隔
- ✅ 喜欢开篇用「引言/背景」建立代入感
- ✅ 喜欢结尾有「总结/关键动作」
- ✅ 喜欢用「表格」呈现对比类信息
- ✅ 喜欢用「代码块」呈现公式/模板
- ✅ 喜欢在结尾加入「互动引导」（如"评论区告诉我..."）

### 禁用风格

- ❌ 过度使用 Emoji（仅限自然点缀）
- ❌ 标题党/夸大其词
- ❌ 纯产品硬广（需植入但要软）
- ❌ 长篇大论不分段

## 📋 各平台内容规范

### 微信公众号

```
篇幅：1500-3000字
结构：引言(痛点/热点) → 核心知识 → 解决方案 → 品牌植入 → 总结
语调：专业、有深度、可信赖
配图：信息图、数据图、品牌视觉
必须包含：文末互动引导、文章来源标注
```

### 小红书

```
篇幅：300-800字（图文笔记）
结构：场景Hook → 体验分享 → 产品亮点 → 行动引导 → 互动标签
语调：真实、有温度、带个人风格
Emoji：自然点缀，非堆砌
标签：3-5个相关话题标签
必须包含：结尾互动问题、收藏引导
```

### 独立博客

```
篇幅：1500-5000字（SEO优化）
结构：H1标题 → 目录导航 → 正文分节 → FAQ → 相关推荐
语调：严谨、客观、有料
SEO：关键词布局、内链外链、结构化数据
必须包含：H2/H3层级标题、Meta描述建议
```

## 🧠 学习到的经验

> 每次生成内容后，将有效的经验沉淀于此

### 标题技巧（已验证有效）

- 数字型：「必须知道的5个变化」
- 疑问型：「准备好迎接这场变局了吗？」
- 利益型：「让AI推荐你的内容」
- 情绪型：痛点前置 + 解决方案后置

### CES/平台算法适配

- 小红书：评论权重 > 收藏 > 转发 > 点赞
- 结尾抛问题比"觉得有用点个赞"效果好3倍

### SEO/GEO要点

- GEO时代：结构化表达、引用权威、QA格式
- E-E-A-T原则：经验、专业、权威、可信

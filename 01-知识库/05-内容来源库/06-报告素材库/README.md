# 报告素材库

> 存放所有抓取的行业白皮书、数据报告、平台官方文档的原文和摘要
>
> **文件命名规范**：`[年份]-[月份]-[报告发布方]-[报告名称].[格式]`
> **示例**：`2026-Q1-小红书商业动态-种草效果化白皮书.pdf`
>
> **摘要命名规范**：`[年份]-[月份]-[报告名]-摘要+选题拆解.md`
> **摘要内容必须包含**：核心数据（3-5 个）/ 关键结论（3-5 条）/ 可拆解选题（5-10 个）

---

## 目录结构

```
06-报告素材库/
├── YYYY-MM/                          ← 按年月分类
│   └── [报告名]/
│       ├── 原文.[pdf/md/html]       ← 原始报告
│       └── 摘要+选题拆解.md           ← AI 提取的核心数据和选题方向
│
├── 榜单快照/                          ← 每日/每周榜单数据存档
│   ├── 新榜-YYYY-MM-DD.md
│   ├── 千瓜数据-YYYY-MM-DD.md
│   └── ...
│
└── README.md                          ← 本文件
```

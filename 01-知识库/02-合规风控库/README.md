# 合规风控库

> 代运营内容的安全红线，AI 必须严格遵守的合规准绳
>
> 核心差异：本库面向商业推广（非医疗），重点在广告法、平台推广规范、敏感行业分类

---

## 📋 违禁词分类

### 1. 绝对化用语（《广告法》第九条）

```
最、第一、顶级、国家级、世界级、史无前例、万能、100%、绝对、彻底、根治、
唯一、独家、首发、顶尖、极致、完美、绝无仅有、前所未有
```

### 2. 功效承诺（《广告法》第二十八条 / 各平台推广规范）

```
保证治愈、根除、彻底解决、一定、有效率 XX%、成功率 XX%、
包你 XX、无效退款（需资质）、用了就 XX、立即 XX、立竿见影
```

### 3. 虚假 / 夸大宣传

```
假一赔十（无法承诺）、伪造数据、虚构用户评价、
冒充权威机构背书、国家级 / 军字号（未认证）
```

### 4. 敏感行业特殊限制


| 行业       | 高风险词           | 所需资质          |
| -------- | -------------- | ------------- |
| 食品 / 保健品 | 功效宣称、疗效用语      | 食品经营许可证、保健品批文 |
| 教育培训     | 考试保证、分数承诺、就业保障 | 办学许可证         |
| 金融       | 收益保证、稳赚、保本     | 金融牌照          |
| 医美 / 护肤  | 医疗效果、换肤、去疤     | 医疗广告审查证明      |
| 房产       | 投资回报、升值保证      | 商品房预售许可证      |


### 5. 各平台推广红线

**微信公众号**：

```
诱导分享（转发领礼品）、诱导关注、刷量行为、
涉及政治/社会事件蹭热度、谣言
```

**小红书**：

```
医美效果夸大、减肥效果对比（真实照片）、带货软文标注不清晰、
素人笔记水军（合规种草可）、医疗/药品推广
```

**独立博客 / 网站**：

```
SEO 作弊（关键词堆砌、隐藏文字、购买外链）、
医疗/药品内容（无资质）、虚假广告
```

## ⚡ AI 审核规则

1. **全局违禁词扫描**：NLP 词法分析，全文匹配违禁词库
2. **行业资质核验**：根据客户行业，检查是否涉及高风险内容
3. **平台规则预判**：分平台判断限流 / 封号风险
4. **自动替换**：黄灯内容按替换表自动修正
5. **红灯拦截**：严重违规内容打回重写

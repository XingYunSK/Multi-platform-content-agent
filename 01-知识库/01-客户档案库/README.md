# 客户档案库

> 存储各代运营客户的所有资料，是 AI 写作的权威素材来源，也是多客户管理的核心

---

## 📂 存放内容

每个客户一个子目录：

```
01-客户档案库/
├── 客户A品牌/
│   ├── 品牌规范.md          # 品牌定位、视觉规范、语调要求
│   ├── 产品资料/            # 产品介绍、功能卖点、核心优势
│   ├── 竞品分析.md          # 竞品对比、差异化卖点
│   ├── 目标人群.md          # 用户画像、痛点分析
│   └── 投放渠道.md          # 已有账号、投放历史
├── 客户B品牌/
│   └── ...
```

## 📋 客户档案模板

```markdown
# [客户名称] 品牌档案

## 基本信息
- **行业**：美妆 / 食品 / 教育 / 科技 / ...
- **品牌定位**：[一句话定位]
- **目标人群**：[用户画像描述]
- **核心卖点**：[TOP 3 差异化优势]

## 推广诉求
- **主要目标**：品牌曝光 / 获客引流 / 销售转化 / 私域沉淀
- **重点平台**：微信公众号 / 小红书 / 独立博客
- **内容禁忌**：[明确禁止的方向]

## 产品矩阵
- **旗舰产品**：[名称 + 核心功效]
- **引流产品**：[名称 + 低价获客款]
- **利润产品**：[名称 + 高客单价款]

## 竞品分析
- **直接竞品**：[品牌名 + 差异化]
- **间接竞品**：[品牌名 + 差异化]

## 合规备注
- 特殊资质要求（如有）：[保健品/医疗/金融等]
- 历史违规记录：[避免重复犯错]
```

## ⚠️ 使用规范

1. **切换客户前必须切换知识库**：AI 写作时必须明确当前服务的客户
2. **产品功效必须溯源**：功效描述须有产品资料支撑
3. **品牌调性必须一致**：同一客户的文章语调、视觉风格需统一
4. **定期更新**：客户产品迭代时同步更新档案

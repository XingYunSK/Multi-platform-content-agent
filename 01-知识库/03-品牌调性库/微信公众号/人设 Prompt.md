# 微信公众号 人设规范

## 定位

深度权威、品牌背书、信任构建

## 语调

专业、有深度、可信赖、有温度

## 篇幅

1500-3000 字长文

## ⭐ 核心写作心法（区别平庸文章的关键）

### 1. 开头必须制造"认知冲突"

**错误示范**（平铺直叙）：

> "5月3日，中央网信办开展专项行动..."

**正确示范**（制造冲突）：

> "一觉醒来，9.8万个账号没了。这不是演习，而是刚刚发生在自媒体圈的真实事件。"

**核心原则**：第一句话就要让读者感到"不对劲"，引发好奇或共鸣。

### 2. 每个段落要有"记忆钉"

**错误示范**（流水账）：

> "数据显示，规范标注来源的内容用户信任度高出40%。"

**正确示范**（有记忆点）：

> "一个有意思的数据是：那些认真标注来源的账号，用户信任度反而高出40%。换句话说，你越坦诚，读者越买账。"

**核心原则**：每个数据后面必须有"人话解读"，不是简单罗列。

### 3. 要有"灵魂拷问"式金句

**金句公式**：

```
现象描述 + 反直觉洞察 + 一句话升华
```

**示例**：

- "内容不是被'做出来'的，而是被'翻出来'的；爆款不是被'推出来'的，而是被'玩出来'的。"
- "真正卡住创作者的，是将创意落地的设计过程。它就像一道隐形门槛，跨不过去，好内容也走不远。"
- "最好的营销，早已不是品牌自导自演，而是放下控制，与用户站在一起。"

### 4. 过渡要自然，不能生硬

**错误示范**：

> "以上就是第一个观点。接下来是第二个观点..."

**正确示范**：

> "但光有热情还不够。接下来要说的，可能会颠覆你的认知..."

**核心原则**：段落之间用"悬念"或"反问"衔接，让读者欲罢不能。

### 5. 案例要有故事性，不能干巴巴

**错误示范**：

> "王者荣耀率先响应，支付宝联名合作，京东紧随其后。"

**正确示范**：

> "48小时内，三家巨头几乎同时官宣：王者荣耀出了皮肤、支付宝搞了联名、京东拉着何润东去了球赛现场。他们没有'创造'什么，只是接住了用户的热情。"

**核心原则**：案例要回答"发生了什么+为什么重要"，而不是简单罗列。

```markdown

### 第三部分：[同上结构]
```

## ⭐ 自检清单（写完必须对照）

- **开头是否制造了认知冲突？** 第一句能否让读者"啊？"一声？
- **每个段落有没有记忆钉？** 读完后能复述出几个核心观点？
- **有没有灵魂金句？** 能否用一句话概括全文核心？
- **过渡是否自然？** 还是生硬地"第一点、第二点、第三点"？
- **案例有没有故事性？** 能否回答"为什么这个案例重要"？
- **有没有反直觉洞察？** 是否只是复述素材，而非提炼新观点？

## 配图规范

- 数量：2-4 张
- 类型：信息图 / 数据图 / 品牌场景图
- 风格：专业、简洁、统一视觉
- 尺寸：横版 16:9 为主

## 标题公式

- 冲突型：《一觉醒来，9.8万个账号没了》
- 反问型：《为什么认真做内容的人，反而越来越难？》
- 反直觉型：《越坦诚，用户越买账》
- 数字型：《3个信号告诉你，自媒体的玩法彻底变了》

## 三、数据使用规范（AI 写作调用指南）

### 引用格式

```
【数据来源】+【具体数值】+【数据周期】

示例：
据 2026 小红书文旅峰会数据，2025 年文旅成交单量同比增长 92%
——来源：运营研究社公众号《小红书文旅种草迈入"效果化时代"》
```

### 数据分级


| 级别   | 说明                 | 引用建议           |
| ---- | ------------------ | -------------- |
| 一级数据 | 平台官方发布（峰会、榜单、官方报告） | 可直接引用，权威性高     |
| 二级数据 | 商家圆桌讨论原声           | 引用时注明"据商家分享"   |
| 三级数据 | 行业经验值（无明确来源）       | 引用时加"据行业经验"    |
| 四级数据 | 软文甲方数据             | 仅作案例参考，不可作权威数据 |


### 避坑提醒

1. **数据时效性**：文旅行业数据变化快，建议引用近 1 年内的数据
2. **数据口径**：DGMV = 履约交易额，与 GMV 口径不同，引用时注意区分
3. **数据来源核实**：第三方软文中的"行业数据"往往无明确来源，引用前需核实
4. **增长数据陷阱**："增长 X 倍" vs "增长 X%" 含义不同，注意换算准确

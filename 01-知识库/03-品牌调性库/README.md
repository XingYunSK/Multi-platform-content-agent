# 品牌调性库

> 存储各账号高赞爆款历史文章，供 AI 进行风格克隆（Few-shot Prompting）
>
> 按客户 × 平台二级分类，支持多客户切换
>
> **核心功能**：为写作 Agent 提供品牌调性分析，生成匹配的内容语气和风格

---

## 🎭 账号人设档案

### 微信公众号

- **定位**：深度权威、品牌背书、信任构建
- **语调**：专业、有深度、可信赖
- **篇幅**：1500-3000 字长文
- **结构**：引言（痛点/热点）→ 核心知识 → 解决方案 → 品牌植入 → 总结
- **配图风格**：信息图、数据图、品牌视觉
- **参考文章**： `./微信公众号/爆款参考/`

### 小红书

- **定位**：种草拔草、生活方式、真实体验
- **语调**：真实、有温度、带个人风格
- **篇幅**：300-800 字（图文笔记）
- **结构**：场景 Hook → 体验分享 → 产品亮点 → 行动引导 → 互动标签
- **Emoji 密度**：中高（自然点缀，非堆砌）
- **配图风格**：真实场景图、对比图、好物分享
- **参考文章**： `./小红书/爆款参考/`

### 独立博客

- **定位**：SEO 长尾流量、专业深度、搜索引擎友好
- **语调**：严谨、客观、有料
- **篇幅**：1500-5000 字（SEO 优化）
- **结构**：H1 标题 → 目录导航 → 正文分节 → FAQ 常见问题 → 相关推荐
- **SEO 要点**：关键词布局、内链外链、结构化数据
- **参考文章**： `./独立博客/爆款参考/`

## 📖 参考原文风格分析

### 原文1：《小红书运营神器3分钟出爆款封面》

**基础信息**

- 来源：运营研究社（公众号）
- 类型：软文（软性推广）| 甲方：Canva 可画

**标题风格**

- 数字型标题："3分钟出爆款封面"
- 利益承诺明确："运营神器"+"3分钟"+"爆款"

**内容结构**

1. 引言：痛点场景（灵魂拷问）→ 数据支撑（80%关联度）
2. 困境分析：三大误区层层递进
3. 解决方案：三个产品亮点逐一展开
4. 品牌价值：个人→团队协作升级
5. 结语：升华主题 + 互动引导

**语气语调特征**

- 专业洞察：善用行业术语和数据背书
- 情绪共鸣：精准戳中创作者痛点（"空有灵感难以落地"）
- 平等交流：不是高高在上的说教，而是"懂你"的陪伴感
- 转化自然：从痛点→方案→品牌价值，层层递进不生硬

**配图风格**

- 封面图：大字报风格，突出"神器"、"3分钟"等关键词
- 内文：以文字内容为主

### 原文2：《小红书文旅种草迈入效果化时代》

**基础信息**

- 来源：运营研究社（公众号）
- 类型：行业分析报告型内容

**标题风格**

- 数字型 + 趋势判断："GMV超3000万"+"效果化时代"
- 权威感强：用数据说话，增强可信度

**内容结构**

1. 开场：数据炸场（五一假期 + GMV数据）
2. 三条路径：线索转化→闭环交易→开环交易
3. 运营方法论：三步走（人群定位→内容种草→转化链路）
4. 结语：趋势洞察 + 互动引导

**语气语调特征**

- 行业报告风格：数据密集、逻辑严谨
- 案例驱动：多个商家案例穿插（春秋旅游、万豪国际等）
- 平台视角：从平台数据和商家案例双线并进
- 专业但不枯燥：用"增收快车道"等生动比喻

**数据来源规范**

- 文中数据用上标标注：①②③...
- 文章末尾设有"数据来源"专门章节
- 格式：序号 + 来源机构 + 内容 + 数据周期

**配图风格**

- 封面图：数字型，突出核心数据（GMV 3000万）
- 内文：可能有数据图表、案例截图

### 参考原文语气风格总结


| 维度       | 特征          | 应用场景      |
| -------- | ----------- | --------- |
| **正式度**  | 正式偏轻松       | 行业洞察但不失温度 |
| **权威感**  | 数据支撑 + 案例背书 | 增强可信度     |
| **情感强度** | 温和有度        | 不煽情但能引发共鸣 |
| **表达风格** | 详尽深入 + 逻辑清晰 | 复杂问题拆解分析  |
| **转化设计** | 痛点→方案→品牌    | 软性植入不生硬   |
| **数据规范** | 上标标注 + 末尾来源 | 专业可追溯     |
